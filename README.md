## 게임 실행

최신 로컬 구현본은 [구현/해체해라-2026-10-07-v01](구현/해체해라-2026-10-07-v01/)에 있습니다.

1. 저장소를 내려받습니다.
2. 해당 폴더의 `index.html`을 Chrome 또는 Edge에서 엽니다. Windows에서는 `게임실행.cmd`를 두 번 클릭해도 됩니다.
3. 저장칸을 선택하고 팀을 만든 뒤 12명의 선수를 준비하고 타자 9명(지명타자 포함)과 선발 투수 1명을 편성합니다.

게임 실행 파일에 그림과 글꼴을 포함하므로 별도 설치나 인터넷 연결 없이 실행할 수 있습니다. 진행도는 브라우저에 저장되며, 다른 주소·브라우저·컴퓨터로 옮길 때 게임의 백업 기능을 사용합니다.

루트의 [index.html](index.html)은 제공된 v27 원본입니다. 새 구현본에는 하단 검사 버튼 제거와 저장 원본 보호·복구 개선이 반영되어 있습니다.

## 야구 규칙 (2026-11-05)

- **끝내기:** 5회 이후 말 공격에서 홈팀이 앞서는 순간 경기가 끝납니다. 홈런이 아니면 결승점까지만 인정합니다. [F08 경기 입장과 시작 조건](구현/해체해라-2026-10-07-v01/문서/SPEC-기능별-2026-10-07-v01/F08-경기-입장과-시작-조건.md)
- **땅볼 진루:** 밀려서 꼭 가야 하는 주자만 반드시 진루합니다. 밀리지 않는 주자는 타구 방향·수비 깊이·주력에 따라 움직이고, 2아웃 전에는 야수선택(앞 주자 포스 아웃)이 나올 수 있습니다. [F14 판정 득점과 리액션](구현/해체해라-2026-10-07-v01/문서/SPEC-기능별-2026-10-07-v01/F14-판정-득점과-리액션.md)
- **태그업:** 외야 뜬공·직선타가 잡히면 주자가 주력과 야구센스로 다음 베이스를 노리고, 외야수 송구에 태그 아웃될 수 있습니다. [F14 판정 득점과 리액션](구현/해체해라-2026-10-07-v01/문서/SPEC-기능별-2026-10-07-v01/F14-판정-득점과-리액션.md)
- **안타 송구:** 안타 때 한 베이스 더 가는 주자를 잡는 송구는 공을 잡은 선수(좌익수·중견수·우익수)의 어깨로 판정합니다.
- **지명타자:** 양 팀 모두 투수 대신 지명타자가 타석에 섭니다. 출전은 타자 9명과 선발 투수 1명입니다. 예전 9명 편성은 라인업을 열거나 경기를 시작할 때 자동으로 바뀝니다. [F05 타순과 수비 편성](구현/해체해라-2026-10-07-v01/문서/SPEC-기능별-2026-10-07-v01/F05-타순과-수비-편성.md)

## 개발과 검사

현재 구현본 폴더에서 실행합니다.

```text
python build.py
python build.py --check
node --test tests/storage.test.cjs tests/player-generation.test.cjs tests/club-events.test.cjs
```

개발용 화면은 `dev.html`이며, `src/`와 `assets/`를 수정한 뒤 `build.py`로 단일 `index.html`을 만들 수 있습니다.

기록된 확인 결과는 경기·운영 규칙 52/52, 심판 판정 16/16, 계약·이적 15/15, 저장 보호 9/9 통과, 자동 3경기 규칙 위반 0입니다. 모든 그림 조합의 시각 품질과 장기 난이도 검증을 완료했다는 뜻은 아닙니다.

별도 검사 페이지 `tests.html?qa=1`은 실제 구단 저장을 읽거나 쓰지 않습니다. 플레이 화면에는 하단 검사 도구를 표시하지 않습니다.

선수 생성은 초기 일반 강점 60~80, 야구센스 강점 55~65, 스태미나 40~60입니다. 영입 선수의 기존 9개 능력은 각각 10~70이며, 선수 한 명당 0.1% 확률로 딱 하나만 80~100이 됩니다. 상세 범위는 F03·F17 SPEC을 참고하세요.

경기 밖 사건 5종은 실제 선수 캐릭터가 움직이는 알림으로 표시합니다. 경기 결과에서 자동으로 열리고 팬·애정도 변화를 확인할 때까지 유지됩니다. 구단 소식의 다시 보기와 설정의 구단 사건 연출 미리보기를 사용할 수 있습니다. [F21 팬·애정도와 구단 소식](구현/해체해라-2026-10-07-v01/문서/SPEC-기능별-2026-10-07-v01/F21-팬-애정도와-구단-소식.md)을 참고하세요.
