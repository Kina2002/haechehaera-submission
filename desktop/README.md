# 해체해라 데스크톱 앱 (Electron)

**만든 날:** 2026-11-11 · 참가자 결정("데스크톱 앱으로, 디자인이나 기능은 언제든 수정 가능하게", 앱은 D 드라이브)

게임을 그대로 감싼 Windows 앱입니다. 화면과 규칙은 모두 [구현 폴더](../구현/해체해라-2026-10-07-v01/)의 `dev.html` · `src/` · `assets/`를 그대로 씁니다. **게임 코드를 고치면 앱에도 그대로 반영됩니다.** 앱 쪽 코드는 이 폴더의 파일 세 개뿐입니다.

| 파일 | 하는 일 |
|---|---|
| `main.js` | 창 열기, 게임 파일을 `app://game/` 주소로 보여 주기, 단축키, 저장 위치, 자가 점검·완성본 만들기 |
| `build-exe.cjs` | 다른 컴퓨터에 복사해도 되는 완성본 폴더(`해체해라.exe`) 만들기 |
| `package.json` | 앱 이름과 시작 파일 |

## 이 컴퓨터 (D 드라이브)

`D:\해체해라-앱\`에 있습니다. 자세한 설명은 그 폴더의 `안내.txt`에 있습니다.

| 바로가기 | 뜻 |
|---|---|
| 해체해라 (고친 코드 바로 반영) | 저장소의 게임 파일을 바로 읽습니다. 코드를 고친 뒤 게임 창에서 **F5** |
| 해체해라 완성본 | `배포\해체해라\해체해라.exe`. 게임 파일이 앱 안에 들어 있습니다 |
| 완성본 다시 만들기 | 지금 게임 파일로 완성본을 새로 만듭니다(약 1분) |

- **단축키:** F5·Ctrl+R 다시 읽기 · F11 전체 화면 · F12 개발 도구
- **저장:** 두 실행 방법 모두 `D:\해체해라-앱\저장`에 저장합니다. 한 번에 하나만 켜집니다. 웹 사이트나 `index.html`로 하던 구단은 게임 안의 백업 파일로 옮깁니다(설정 → 이 팀의 백업 파일 내려받기 → 앱의 빈 저장칸 → 파일 불러오기).
- **Electron:** v44.10.0(2026-10-27 공식 배포본)을 [GitHub 배포 페이지](https://github.com/electron/electron/releases/tag/v44.10.0)에서 받아 SHA256을 확인했습니다. 저장소에는 넣지 않습니다(약 360MB).

## 왜 `app://` 주소인가

`file://`로 `dev.html`을 열면 소리 파일을 `fetch`로 읽을 수 없습니다. 그래서 앱이 게임 폴더를 `app://game/` 주소로 보여 줍니다. 게임 폴더 밖의 파일은 열지 않습니다. 개발용과 완성본이 같은 주소를 쓰므로 같은 저장을 씁니다.

## 다른 컴퓨터에서 처음 설정하기

1. [Electron 배포 페이지](https://github.com/electron/electron/releases/tag/v44.10.0)에서 `electron-v44.10.0-win32-x64.zip`을 받아 원하는 곳(예: `D:\해체해라-앱\electron`)에 풉니다. 같은 페이지의 `SHASUMS256.txt`로 확인할 수 있습니다.
2. 실행: `electron.exe "<저장소>\desktop" --data-dir="<저장 폴더>"`
3. 완성본: `electron.exe "<저장소>\desktop" --build-exe --out="<배포 폴더>" [--data-dir="<저장 폴더>"]`. `--data-dir`를 빼면 완성본은 `.exe` 옆 `저장` 폴더에 저장합니다.

## 확인한 것 (2026-11-11)

- 자가 점검 `electron.exe "<저장소>\desktop" --self-check=결과.png --data-dir=<임시 폴더>`: 개발용·완성본 모두 저장 선택 화면이 열리고, 오류 0개, `fetch`로 게임 파일 읽기 성공, 다시 켜도 저장이 남음
- 완성본 크기 약 439MB(Electron 367MB + 게임 72MB)

## 아직 아닌 것

- 아이콘은 Electron 기본 아이콘입니다. 바꾸려면 아이콘 파일과 도구(rcedit)가 더 필요합니다.
- 설치 프로그램(setup.exe)은 없습니다. 완성본 폴더를 통째로 복사해서 씁니다.
- 큰 모니터에서 화면이 꽉 차지 않는 것은 게임 화면 최대 너비(1,560픽셀) 때문이라 앱으로 바뀌지 않습니다([향후 목록](../구현/해체해라-2026-10-07-v01/문서/SPEC-기능별-2026-10-07-v01/향후-구상과-보류.md#화면-꽉-채우기와-전체-화면)).
