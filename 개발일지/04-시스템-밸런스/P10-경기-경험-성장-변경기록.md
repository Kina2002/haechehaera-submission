## 실수와 고칠 점

| 무엇이 있었나 | 어떻게 고쳤나 |
|---|---|
| 젊은 선수 시험 v01·v02는 참가자의 실제 나이 규칙(P21)이 GitHub에 올라오기 전이라 Claude 임시 나이 가정을 썼습니다. v01의 시험용 감독은 나이를 보지 않고 훈련·영입했습니다. | v02에서 나이를 보는 감독으로 바꿨고, P21 규칙이 올라온 뒤 다시 시험했습니다. |

## 다음엔 이렇게

- 시험용 감독 규칙(훈련·영입·출전·은퇴)이 결과를 크게 바꿉니다. 시험마다 감독 규칙을 먼저 적어 둡니다.
- 참가자 규칙이 아직 없으면 임시 가정임을 표와 제목에 밝히고, 실제 규칙이 오면 다시 시험합니다.
- 보너스가 효과 없을 때는 숫자를 바꾸기 전에, 보너스가 쓰일 기회(출전)가 있는지 먼저 봅니다.
- 20\~40구단 시험은 비율이 약 ±10\~15%p(퍼센트포인트) 흔들립니다. 차이가 그보다 작으면 같은 수준으로 봅니다.

## 정리 뒤 새 시험

### 경기당 경험치 측정 · 2026-11-11

참가자가 "경험치가 얼만큼 오르는지 구체적으로 정하자"고 해서, 지금 초안 공식으로 선수가 한 경기에 실제로 받는 경험치를 쟀습니다. 실제 경기 판정(게임 코드)으로 400경기씩 돌렸고, 배수(리그·나이·시설)를 곱하기 전 값입니다.

- 실행: `node tests/measure-exp-per-game.cjs 400` (동네 수준: 시작 선수 vs 동네 중위권 39 · 2부 수준: 우리 +20 vs 2부 중위권 63)
- 타자는 한 경기에 평균 약 2.4타석, 투수는 아웃 약 15개였습니다. 야수는 경기당 본헤드를 약 0.5번 했습니다.

| 능력 | 야수 | 지명타자 | 투수 | 능력 49 이하일 때 +1까지 |
|---|---:|---:|---:|---:|
| 컨택 | 2.5 | 3.4 | - | 약 4경기 |
| 파워 | 0.5 | 1.2 | - | 약 20경기 |
| 선구안 | 1.3 | 1.2 | - | 약 8경기 |
| 주력 | 1.0 | 0.9 | - | 약 10경기 |
| 야구센스 | 2.4 | 1.5 | 1.0 | 약 4경기 |
| 포구 | 1.9 | - | - | 약 5경기 |
| 송구 | 1.0 | - | - | 약 10경기 |
| 제구 | - | - | 7.5 | 약 1.3경기 (투수) |
| 구속 | - | - | 5.1 | 약 2경기 (투수) |
| 스태미나 | - | - | 4.5 | 약 2경기 (투수) |

2부 수준에서는 안타가 줄어 야수 컨택이 2.5 → 2.0, 투수 구속이 5.1 → 3.9였습니다.

**찾은 것과 바뀐 것**

1. **투수가 타자보다 3\~5배 빨리 컸습니다.** 아웃 하나하나가 경험치이기 때문입니다.
2. **파워는 2시즌에 +1 정도로 아주 느렸습니다.** 장타가 드뭅니다.
3. **맡은 일 밖의 능력은 전혀 크지 않았습니다(표의 "-").** 참가자는 "주포지션이 너무 굳어진다"며, 모든 역할이 모든 능력에서 클 수 있어야 한다고 했습니다.
4. Claude는 모든 능력에 기본 경험치 0.3을 주는 안을 냈습니다. 참가자는 "무조건 채우지 말고 **그 능력을 쓰는 사건이 일어날 때** 오르게" 하자고 했고, 역할별 사건 표를 직접 고쳐 정했습니다([P10](../../구현/해체해라-2026-10-07-v01/문서/SPEC-기능별-2026-10-07-v01/P10-경기-경험-성장.md) "경험치가 오르는 사건"). 사건마다 숫자는 다음에 정합니다.

### 사건 방식 경험치 v01 · 2026-11-11

참가자가 정한 사건 표에 Claude가 숫자를 붙인 v01을 시험했습니다("이대로 재 봐"). 방향은 타자·야수 약 20% 줄이기, 투수는 타자와 속도를 맞추려 절반쯤 줄이기, 새 칸은 작게였습니다. 숫자는 [exp-events.cjs](../../구현/해체해라-2026-10-07-v01/tests/exp-events.cjs)의 `EXP_EVENTS`에 있습니다.

- 시뮬레이터가 경기 판정의 사건 기록(투구마다 누가 타구를 처리했는지, 플레이 종류)을 읽어 우리 팀 사건을 세게 했습니다. 게임 코드는 바꾸지 않았고, 끄면 기존 결과가 숫자 하나까지 같습니다.
- 시뮬레이터에는 대타·대수비·불펜 교체가 없어서, 투수의 타격 칸과 지명타자의 수비 칸은 시험에서 생기지 않았습니다.
- 실행: `node tests/measure-exp-per-game.cjs 400`(경기당), `node tests/run-economy-sim.cjs 40 결과.json shape t4g10e <유저> 25`(성장). 비교 대상은 [리그 모양 비교](P09-시즌-리그-해체여론-변경기록.md#리그-모양-비교--2026-11-11-v02)의 4단계 · 10경기(지금 공식)입니다.

**경기당 경험치 (동네 수준, 400경기, 배수 전)**

| 능력 | 야수 지금 → 사건 | 지명타자 지금 → 사건 | 투수 지금 → 사건 |
|---|---|---|---|
| 컨택 | 2.5 → 2.0 | 3.4 → 2.7 | 0 → 0 |
| 파워 | 0.5 → 0.4 | 1.2 → 0.9 | 0 → 0 |
| 선구안 | 1.3 → 1.0 | 1.2 → 1.1 | 0 → 0.9 |
| 주력 | 1.0 → 0.8 | 0.9 → 0.7 | 0 → 0.7 |
| 야구센스 | 2.4 → 1.7 | 1.5 → 1.2 | 1.0 → 2.7 |
| 포구 | 1.9 → 0.9 | 0 → 0 | 0 → 1.4 |
| 송구 | 1.0 → 0.4 | 0 → 0 | 0 → 1.1 |
| 구속 | 0 → 0.03 | 0 → 0 | 5.1 → 2.7 |
| 제구 | 0 → 0.15 | 0 → 0 | 7.5 → 4.5 |
| 스태미나 | 0 → 0.9 | 0 → 0.9 | 4.5 → 2.4 |
| 합계 | 10.5 → 8.3 (−22%) | 8.1 → 7.5 (−8%) | 18.2 → 16.5 (−9%) |

경기당 사건 횟수(야수 한 명): 타구를 잡아 아웃 1.1 · 송구로 아웃 0.5 · 병살 처리 0.05 · 외야 보살 0.02 · 도루 저지 0.06. 투수: 투수 앞 타구 1.3 · 1루 커버 0.9 · 헛스윙 유도 9.3 · 볼넷 없는 이닝 3.8 · 주자 있을 때 무실점 이닝 2.4 · 5이닝 이상 던진 경기 81%.

**성장과 리그 (세 유저 × 40구단 × 25시즌)**

| 유저 | 1부 도달 지금 → 사건 | 25시즌 뒤 출전 평균 | 해체 1번 이상 | MLB 진출 (구단당) |
|---|---|---|---|---|
| 아끼는 | 47.5% → 30% | 61.0 → 58.7 | 7.5% → 10% | 6.4 → 3.7 |
| 보통 | 60% → 40% | 62.2 → 59.5 | 5% → 17.5% | 13.3 → 9.7 |
| 무리하는 | 55% → 37.5% | 61.7 → 61.1 | 47.5% → 50% | 15.4 → 12.2 |

**찾은 것**

1. 경험치를 줄인 만큼 성장이 느려졌습니다. 보통 유저의 출전 평균이 25시즌 뒤 약 2.7 낮고, 1부 도달이 60% → 40%로 줄었습니다. 해체는 늘었습니다(보통 5% → 17.5%). 해체를 더 자주 일어나게 하자는 [P27](../../구현/해체해라-2026-10-07-v01/문서/SPEC-기능별-2026-10-07-v01/P27-해체를-성장의-기회로.md) 방향과는 맞습니다.
2. 투수가 공을 자주 처리합니다(경기당 1.3개). 그래서 투수의 포구·송구가 야수보다 빨리 컸습니다.
3. "주자 있을 때 실점 없이 막은 이닝"이 경기당 2.4번이라 투수 야구센스가 2.7로 컸습니다.
4. 야수의 수비 경험치가 절반으로 줄었습니다. 예전 식은 자리에 서기만 해도 받았고, 사건 방식은 실제로 공을 처리해야 받습니다.
5. 야수가 구속·제구로 크는 사건(외야 보살)은 경기당 0.02번으로 아주 드뭅니다.

### 사건 방식 경험치 v02p (투수만 바꿈) · 2026-11-11

v01을 보고 참가자가 "야수는 그대로 두고 투수만 바꾸면?"이라고 했습니다. 투수 앞 타구 처리·송구 0.8 → 0.3, 주자 있을 때 무실점 이닝 0.8 → 0.3, 볼넷 없는 이닝 0.4 → 0.2로 바꿨습니다(`EXP_PRESETS.v02p`). 실행: `node tests/measure-exp-per-game.cjs 400 v02p`, `node tests/run-economy-sim.cjs 40 결과.json shape t4g10p <유저> 25`.

**투수 경기당 경험치 (동네 수준)**

| 능력 | 지금 공식 | v01 | v02p |
|---|---:|---:|---:|
| 야구센스 | 1.0 | 2.7 | 1.5 |
| 포구 | 0 | 1.4 | 0.7 |
| 송구 | 0 | 1.1 | 0.4 |
| 제구 | 7.5 | 4.5 | 3.8 |
| 구속 · 스태미나 · 선구안 · 주력 | 5.1 · 4.5 · 0 · 0 | 2.7 · 2.4 · 0.9 · 0.7 | 같음 |
| 합계 | 18.2 | 16.5 | 13.2 (−27%) |

**성장과 리그 (세 유저 × 40구단 × 25시즌)**

| 유저 | 1부 도달: 지금 → v01 → v02p | 25시즌 뒤 출전 평균 | 해체 1번 이상 |
|---|---|---|---|
| 아끼는 | 47.5% → 30% → 27.5% | 61.0 → 58.7 → 57.3 | 7.5% → 10% → 20% |
| 보통 | 60% → 40% → 25% | 62.2 → 59.5 → 59.2 | 5% → 17.5% → 12.5% |
| 무리하는 | 55% → 37.5% → 40% | 61.7 → 61.1 → 58.8 | 47.5% → 50% → 40% |

**찾은 것**

1. 투수 경험치를 줄이니 보통 유저의 1부 도달이 40% → 25%로 더 줄었습니다. 이 게임 판정에서는 투수의 힘이 승패에 크게 걸립니다. 40구단 기준 오차가 약 ±15%p라 차이의 크기는 조심해서 봐야 하지만, 방향은 세 유저에서 대체로 같았습니다(무리하는 유저만 비슷).
2. 역할 사이 균형(투수 수비·야구센스가 야수와 비슷)은 v02p가 낫고, 리그를 올라가는 속도는 v01이 낫습니다.

### 전체 크기 맞추기 (목표: 보통 유저 1부 약 50%) · 2026-11-11

참가자가 목표 난이도를 "보통 유저가 25시즌 안에 1부에 가는 비율 50% 정도"로 정했습니다. v02p의 사건 구성과 역할 사이 비율은 그대로 두고, 모든 사건 숫자에 같은 배수(×1.2, ×1.35)를 곱해 시험했습니다(`scaleExp`, 모양 `t4g10p12`·`t4g10p135`).
