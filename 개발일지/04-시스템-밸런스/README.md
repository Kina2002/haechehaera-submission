# 04 시스템·밸런스 — 게임 규칙을 시뮬레이션으로 정한 과정

게임의 큰 규칙(리그, 해체 여론, 돈, 성장, 나이, MLB, 시설)을 어떻게 정했는지 기록합니다. 기획 문서(P)에는 "지금 정해진 규칙"만 남기고, 시험 결과와 바뀐 과정은 이 폴더에 둡니다.

**기준일:** 2026-11-11 · 기간: 2026-11-09 \~ 11-11 · 게임 코드는 아직 바꾸지 않았고, 기획과 시뮬레이션만 했습니다.

## 일하는 방식

1. 참가자가 원하는 경험을 말합니다. 예: "MLB에 간 선수가 힘들 때 모구단을 돕는다."
2. Claude가 규칙과 숫자 초안을 만들고, 자금 시뮬레이터에 넣어 가상 감독(아끼는·보통·무리하는)으로 여러 시즌을 돌립니다.
3. 결과를 표로 보여 주고, 참가자가 고르거나 숫자를 고칩니다.
4. 정한 것은 기획 문서에, 시험은 이 폴더와 결과 파일에 남기고 GitHub에 올립니다.

**시뮬레이터:** [run-economy-sim.cjs](../../구현/해체해라-2026-10-07-v01/tests/run-economy-sim.cjs)는 실제 게임의 경기 판정 코드를 그대로 불러와 쓰고, 규칙을 하나씩 "켜고 끄는" 설정으로 더했습니다(리그, 성장, 해체, 대출, MLB, 원정, 시설, 리그별 수입, 나이, 영입 시장, 세 유저, MLB 보상). 새 규칙을 더할 때마다 **끈 상태에서 예전 결과가 숫자 하나까지 똑같이 나오는지** 확인했습니다.

## 실수와 고칠 점

| 무엇이 있었나 | 어떻게 고쳤나 | 다음엔 이렇게 |
|---|---|---|
| 시험용 감독의 행동이 결과를 크게 바꿨습니다. 시설 개편 v01에서는 감독이 확장비를 모으는 동안에도 남는 돈을 훈련에 써서, 15시즌 내내 경기장을 넓히지 못했습니다([P17 기록](P17-시설과-경기장-개편-변경기록.md)) | v01을 버리고 감독 규칙을 고쳐 v02로 다시 돌렸습니다 | 결과가 이상하면 규칙보다 **감독 설정부터 의심**합니다. 감독 규칙을 문서에 적어 둡니다 |
| 시험 감독은 조건이 되면 늘 MLB에 보냈습니다. 그래서 돈을 늘리면 오히려 선수가 더 떠나 1부가 늘지 않았습니다 | "MLB 안 보내는 감독"과 비교해 원인을 따로 쟀습니다 | 실제 이용자와 다르게 행동하는 부분을 따로 시험합니다 |
| 나이 규칙이 아직 GitHub에 없을 때, Claude가 임시 가정(33세부터 하락, 37세 은퇴)으로 젊은 선수 보너스를 시험했습니다 | 참가자의 실제 규칙(P21)이 올라온 뒤 다시 시험했습니다 | 정해지지 않은 규칙으로 시험할 때는 **임시 가정임을 표와 제목에 밝힙니다** |
| 젊은 선수 보너스가 효과 없어 보였습니다. 새 선수가 약해 후보에 머물렀고, 후보는 경기 경험치를 받지 못했기 때문입니다 | 리그별 영입 시장(P20)을 넣자 보너스가 효과를 냈습니다 | 숫자만 바꾸지 말고 **왜 효과가 없는지**부터 찾습니다 |
| 참가자가 배수를 "동네 ×0.1"로 적었는데 ×1.0의 오타였습니다 | 기록하기 전에 확인 질문으로 바로잡았습니다 | 지나치게 큰·작은 숫자는 기록 전에 한 번 확인합니다 |
| 1부에서 바로 강등되는 것을 "문제"로 봤지만, 참가자는 "1부는 원래 압도적"이라는 의도였습니다 | 그대로 두기로 했습니다 | 문제를 고치기 전에 **의도된 어려움인지** 먼저 묻습니다 |
| 결정과 시험 기록이 한 문서(P09)에 몰렸고, 뒤에는 기획 문서마다 시험 기록이 쌓여 길어졌습니다 | 주제별 P 문서로 나눴고(11-09), 시험 기록은 이 폴더로 옮겼습니다(11-11) | **"정해진 것"과 "정한 과정"을 처음부터 다른 문서에** 씁니다 |
| 20\~40구단 시험은 비율이 ±10\~15%p 흔들립니다. 원정 응원 30%의 2부 승격이 20%보다 낮게 나온 적이 있습니다 | 결과마다 오차를 함께 적었습니다 | 차이가 오차보다 작으면 "같다"고 봅니다. 중요한 결정은 구단 수를 늘려 확인합니다 |
| 직관과 반대인 결과가 있었습니다. 경기장 승격 조건은 오히려 승격을 도왔고(넓힌 경기장이 1시즌 안에 본전), MLB 능력 보상을 키우면 선수가 더 많이 떠났습니다 | 결과를 그대로 기록하고 숫자를 다시 맞췄습니다 | 예상과 다른 결과일수록 기록해 둡니다 |

## 다음엔 이렇게

- **목표 숫자를 먼저 정하고 시험합니다.** 예: "보통 감독이 20시즌 안에 30\~50% 정도 1부에 간다." 목표가 있어야 숫자를 맞출 수 있습니다.
- **한 번에 하나만 바꿔 비교합니다.** 후보마다 같은 시작 상태(같은 운)에서 돌리면 차이가 후보 때문인지 알 수 있습니다.
- **재현 명령을 남깁니다.** 원자료가 크면(예: 33MB) 저장소에는 요약과 실행 명령만 남깁니다.
- **실제 규칙과 임시 가정을 구분해 씁니다.**
