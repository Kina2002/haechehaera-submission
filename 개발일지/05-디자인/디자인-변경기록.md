## 1. 경기장 표현과 경기 진행 (11-05)

### 원근감 개선 시안 v01

**무엇이 바뀌었나** 실제 게임 화면 위에 네 가지를 덧붙이고, 버튼 하나로 수정 전/후를 바꿔 보게 했습니다. 원근은 가까운 것은 크게, 먼 것은 작게 그리는 방식입니다.

| 항목 | 그때 게임 | 시안 |
|---|---|---|
| 원근 | 0.76배(가장 먼 외야)\~1.56배(홈) | 0.55배\~1.50배. 외야수 약 0.79배 → 0.60배 |
| 발밑 그림자 | 가로 12×세로 3의 연한 그림자 | 더 넓고 진한 부드러운 그림자 + 발 바로 아래 진한 부분 |
| 심판 | 위치와 관계없이 크기 고정 | 선수와 같은 원근 비율, 그림자 포함 |
| 먼 거리 색 | 모든 선수가 같은 선명도 | 외야 쪽 선수의 채도(색의 진하기)를 최대 30% 낮추고 밝기 5% 올림 |

강도 막대로 원근의 세기를 0\~150%로 조절할 수 있었습니다.

**왜** 캐릭터가 배경 위에 떠 있는 것처럼 보이는 문제를 줄이려고 했습니다.

**결과** 네 항목은 같은 날 PR #40(커밋 07030fb)으로 게임에 들어갔습니다. PR #40은 선수 외곽선과 대기 자세도 더했습니다. PR #41·#42에서 선수 방향, 화면 해상도, 심판 위치, 구역별 선수 크기를 다듬었습니다.

**실수·고칠 점** 시안 README에는 지금도 "아직 실제 게임에 적용하지 않은 시안"이라고 적혀 있습니다. 적용 사실은 11-09 커밋 1ab9512의 설명에만 있습니다.

### 승부처 개입 시안 v01

**무엇이 바뀌었나** 자동 경기를 보다가 승부처에서만 경기를 멈추고 감독에게 지시를 묻습니다.

- 승부처 4가지: 득점 기회, 끝내기 기회, 실점 위기, 우리 투수 체력 30% 이하.
- 10초 안에 고르지 않으면 초록색 자동 판단대로 진행합니다.
- 빈도는 '가끔'(4회 이후 1점 차 이내, 반 이닝에 한 번)과 '자주'(3회 이후 2점 차 이내, 타석마다) 중에서 고릅니다.
- 번트·고의4구는 게임 규칙에 없어 넣지 않았습니다. 이미 공마다 지시하는 반자동 경기에는 띄우지 않습니다.

**왜** 기록에 없음.

**상태** 게임에 적용하지 않았습니다(11-09 커밋 1ab9512 설명 기준).

## 2. 경기 화면 배치 (11-09 \~ 11-10)

기존 화면은 경기장 밖의 정보가 차지하는 공간이 커서, 선수 움직임과 성격별 동작을 보여 줄 여지가 작았습니다. 그래서 경기장 구도와 정보 배치를 먼저 정하고 캐릭터 작업을 이어 가기로 했습니다(결정사항 11-09).

### 중계 화면 시안 v01

**무엇이 바뀌었나** TV 야구 중계처럼 경기장을 화면 가득 깔고 정보는 모서리에 작게 띄웠습니다. 홈플레이트가 있는 아래 가운데는 비웠습니다. 공격 때는 카메라를 약 1.2배 가깝게, 수비 때는 넓게 했습니다.

| 1536×864 노트북 화면 | 그때 화면 | 새 화면 |
|---|---|---|
| 경기장 그림 | 화면의 약 48% | 약 97% |
| 그라운드(관중석 제외) | 약 31% | 약 78% |
| 선수 크기 | 1배 | 약 1.7배 |
| 조작 버튼 | 스크롤해야 보임 | 항상 보임 |

**왜** 경기장 밖 정보가 공간을 많이 차지하는 문제(위)를 풀려고 했습니다.

**확인** 자동 경기에서 플레이 17번과 공수 교대 1번 동안 오류가 없었습니다. 휴대폰처럼 좁은 화면은 확인하지 않았습니다.

### 중계 집중형 v01 → v04

하루(11-09)에 네 버전을 만들었습니다. 버전마다 참가자의 요청 하나를 반영했고, 이전 버전은 보존했습니다.

**v01**

- **무엇이 바뀌었나** 기존 게임의 경기장·선수·시뮬레이션을 불러오는 독립 미리보기(게임과 따로 여는 화면)입니다. 위에 7이닝 점수판(R/H/E)과 볼·스트라이크·아웃, 오른쪽에 현재 공격 팀 9명(현재 타자는 노란색), 아래에 현재 타자·지시 버튼·현재 투수를 두었습니다.
- **왜** 중계 집중형과 감독석형을 대화용 배치 그림으로 비교한 뒤 중계 집중형을 골랐습니다. 그다음 실제 게임 그림으로 화면을 확인하려고 만들었습니다.
- **실수·고칠 점** 감독석형 비교 그림은 시안 폴더에 남아 있지 않습니다. 고르지 않은 이유도 기록에 없음.

**v02**

- **무엇이 바뀌었나** 공격은 홈 뒤에서 가깝게, 수비는 높은 곳에서 넓게 보는 카메라입니다. 타구가 나오면 화면을 넓혔다가 다음 투구 때 돌아옵니다.
- **왜** 참가자가 고른 방향입니다.
- **실수·고칠 점** 기존 2D 경기장 그림의 보이는 범위만 바꿨습니다. 그래서 "각도 차이 대신 확대 차이에 그쳤"습니다(결정사항 11-09).

**v03**

- **무엇이 바뀌었나** 경기장 바닥을 새 원근으로 그리고, 기존 선수 포즈를 새 위치에 세운 포수 뒤 낮은 시점입니다. 타격·주루 때만 높은 전체 구도로 바꾸고, 볼·스트라이크 때는 낮은 시점을 유지합니다.
- **왜** 참가자가 "단순 확대가 아니라 포수가 바라보듯 낮고 수평적인 공격 시점"을 요청했습니다.
- **결과** 참가자가 원하는 구도라고 확인했습니다.
- **실수·고칠 점** 가까운 1·3루가 화면 밖에 있었습니다.

**v04** — 실행해 볼 수 있는 최신 비교본

- **무엇이 바뀌었나** 앞쪽 구도·선수 크기·카메라 높이를 유지하고, 먼 내야의 가로 범위를 넓혔습니다. 1·3루 베이스와 주자, 수비수가 화면 안에 들어오고 1루/3루 표식을 붙였습니다.
- **왜** 참가자가 v03의 각도는 맞고 1루와 3루도 모두 보이게 해 달라고 했습니다.
- **확인** 1366×768과 1280×720에서 넘침 없이 타순 9명이 보였습니다. 자동 3배속 경기에서 낮은 시점과 타격 후 전체 구도 전환을 확인했습니다. 최종 오프라인 파일에서 실제 저장소 읽기·쓰기가 없었습니다. 장기 플레이·모든 화면 크기·모든 선수 조합은 확인하지 않았습니다.
- **다음엔 이렇게** 결정사항 11-09는 낮은 시점에서 주자·투수·타자·말풍선이 겹치는 상황과, 여러 체형·좌우타자 조합을 더 보라고 남겼습니다.

v04를 최종 확정한 것은 아닙니다.

### 경기장 일체형 화면 v01 → v02 — 현재 선호 방향

**v01**

- **무엇이 바뀌었나** 정지 그림 1장입니다. 바깥의 상단·우측·하단 정보 칸을 없애고 경기장이 화면 전체를 채웁니다. 구장 안 전광판에 점수판과 현재 공격 팀 9명을 넣었습니다. 홈 주변 빈 잔디에 타자·투수 정보를, 타석 옆에 풀스윙·컨택·참기 버튼을 작게 두었습니다.

**왜**

**무엇이 바뀌었나** 경기장 안 타자·주자의 동작 의견을 정리했습니다. 사용자가 제시한 기본 7개(좌·우타 타격폼, 진루와 홈인, 홈런 세리머니, 슬라이딩, 삼진, 아웃, 공이 먼저 도착)와 대화에서 긍정적으로 본 후보 10개(타석 입장 루틴, 슬라이딩 이후, 일반 득점 후 등)입니다. 비슷한 장면을 나누는 기준도 적었습니다.

**왜** 그림을 만들기 전에 무엇이 필요한지 정리하려고 했습니다. 제작 범위·우선순위·그림 수는 정하지 않았습니다.

**무엇이 바뀌었나** 중계 집중형 v04 경기장의 선수 위치에 6체형 뼈대를 세웠습니다. 원본 PNG를 잘라 그리며 체형별 키 차이를 유지합니다. '새 뼈대/기존 선수'를 바꿔 보고, 선수 크기를 75\~135%(기본 100%)로 조절할 수 있습니다.

## 돌아보며

- **작은 버전을 빨리, 하나씩 고쳤습니다.** 중계 집중형은 11-09 하루에 v01에서 v04까지 갔습니다. 버전마다 참가자의 요청 하나(가깝게 → 낮고 수평으로 → 1·3루도)를 반영했고, 이전 버전은 지우지 않았습니다.
- **결정은 따로, 날짜·버전마다 새 파일로 적었습니다.** 결정사항 문서에 선택·검토 중·미확정·중단을 나눠 적었습니다. 11-09에 멈춘 캐릭터 작업을 11-10에 이 기록에 이어서 다시 시작했습니다.
- **시안과 실제 게임을 분리했습니다.** 시안은 `구현/` 원본을 바꾸지 않고 시험 모드로 실행했습니다. 약 100MB 실행 파일은 저장소에 넣지 않고 소스와 `build-single.py`로 다시 만듭니다. 원근감 시안은 수정 전/후를 비교한 뒤 같은 날 게임에 들어갔습니다.
- **화면을 줄이면 빠지는 것이 생깁니다.** 일체형 v01에서 얼굴·조작부·작은 기록이 빠졌습니다. v02에서 되살리고 "빼지 않을 요소" 목록을 만들었습니다.
- **기준 외형을 먼저 정해야 합니다.** 폼 v01은 다른 외형으로 그려 v02로 다시 만들었습니다. 캐릭터 요청문 v02도 한 명의 그림체를 먼저 정하는 순서로 바꿨습니다.
- **그림 시안의 한계를 매번 적었습니다.** 생성 그림은 게임 엔진의 좌표로 그린 화면이 아니고, 40px 스프라이트나 파츠 결합을 검증한 것도 아니라고 README마다 밝혔습니다.
