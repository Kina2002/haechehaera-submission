**용어**

- **BGM:** 배경음악. **효과음:** 타격·판정처럼 짧은 소리.
- **BPM:** 1분에 들어가는 박자 수. 클수록 빠릅니다.
- **WAV / MP3:** WAV는 압축하지 않은 원본, MP3는 작게 압축한 파일입니다.
- **TTS:** 글자를 목소리로 읽어 주는 음성 합성입니다.
- **MIDI / 악기 음원(SoundFont):** MIDI는 음 높이·길이를 적은 악보 데이터이고, SoundFont는 그 악보를 실제 악기 소리로 연주할 때 쓰는 소리 모음입니다.
- **CC0 · 퍼블릭 도메인:** 만든 사람이 권리를 내려놓아 누구나 쓸 수 있게 공개한 방식입니다.
- **RMS · dB:** 평균 음량과 그 차이를 나타내는 값입니다. 숫자가 커져도 귀로 그만큼 커졌다는 뜻은 아닙니다.

## 시안별 기록

### v01 · 첫 BGM과 효과음

**무엇이 바뀌었나**

- 도트 야구게임에 맞춰 경기장 오르간, 레트로 전자음, 따뜻한 전자 피아노로 만들었습니다. 멜로디·화성·리듬을 직접 쓰고 합성 음색을 썼습니다. 기존 곡, 음원 샘플, 사람 목소리, 관중 녹음은 쓰지 않았습니다.
- BGM 3곡: 「오늘도 해체는 없다」(메인·일반 경기, 32.0초·120 BPM), 「우리 동네 야구단」(구단 운영·사인회·기부, 31.3초·92 BPM), 「9회말 풀카운트」(접전·위기, 28.2초·136 BPM).
- 효과음 14개: 타격, 포구, 헛스윙, 스트라이크, 아웃, 홈런, 승리, 패배, 업적, 좋은 사건, 나쁜 사건, MLB 진출, 메뉴 선택, 선택 완료.
- 18개 WAV의 형식·길이·무음·진폭을 자동 검사했습니다. 듣기 평가는 사용자 확인으로 남겼습니다.

**왜** 소리의 방향을 고르기 위한 첫 시안입니다. 관중 함성, 심판의 실제 음성, 사건별 긴 음악은 이번에 만들지 않았습니다.

**결과** BGM 3곡과 효과음 9개(포구·승리·패배·업적·좋은 사건·나쁜 사건·MLB·메뉴 선택·선택 완료)는 고치지 않고 그대로 게임에 들어갔습니다.

### v02 · 다섯 가지 효과음 개선

**무엇이 바뀌었나**

- 홈런 타격음을 새로 만들었습니다. 최대 음량은 키우지 않고, 일반 타격과 음색으로 구분되는 더 선명한 "딱!"입니다.
- 헛스윙은 길게 새는 고음 잡음을 줄인 약 0.18초의 "휙!"으로 바꿨습니다.
- 스트라이크는 짧은 충격음과 힘 있는 높은 음, 아웃은 낮고 단단한 충격음으로 바꿨습니다.
- 홈런 축하는 오르간 선율 대신 폭죽 네 번과 잔불이 이어지는 4초 합성음으로 바꿨습니다.

**왜** 기록에 없음. README에는 v01 헛스윙의 "뱀처럼 길게 새는 고음 잡음"을 줄였다는 설명만 있습니다.

**실수·고칠 점** 합성 헛스윙은 결국 쓰지 않았습니다. 사용자가 준 파일로 바꿨습니다(아래 사용자 선택).

### v03 · 심판 목소리와 실제 불꽃놀이 — 보류

**무엇이 바뀌었나**

- "스트라이크!"(1.33초)와 "아웃!"(0.63초)을 Microsoft Edge TTS의 일반 합성 남성 목소리로 만들었습니다. 영어 "Strike!"·"Out!"도 비교용으로 만들었습니다.
- 홈런 축하는 실제 불꽃놀이 녹음(stephan, Wikimedia Commons, 퍼블릭 도메인)의 43.35\~50.85초를 편집한 7.64초 소리입니다.

**왜** README 표의 제목이 "이번 요청 반영"입니다. 요청의 원문은 기록에 없음.

### v08 · 성우 녹음에서 자른 판정 A/B

**무엇이 바뀌었나**

- 훈련받은 성우의 심판 콜 녹음(jcookvoice, Freesound 625473, CC0)에서 단어를 잘라냈습니다. 스트라이크 0.35초, 아웃 1.12초, 세이프 0.68초입니다.
- A는 원래 발성, B는 낮은 울림(130\~360Hz)과 약한 압축을 더한 굵은 버전입니다. 판정별 A/B 평균 음량 차이를 0.01dB 이내로 맞춰 음색만 비교하게 했습니다.

**왜** 사용자가 "실제 심판처럼 굵고 힘 있게"라는 방향을 골랐습니다.

**실수·고칠 점** 단어 구간을 찾으려고 쓴 로컬 음성 인식이 거친 외침을 일부 잘못 알아들었습니다. 그래서 발음이 자동으로 검증됐다고 보지 않았습니다.

### v09 · 세이프를 닮은 AI 스트라이크·아웃

**무엇이 바뀌었나**

- v08의 세이프 B를 참고 음성으로 넣고, AI 음성 모델 Chatterbox-Nano(MIT 라이선스)로 "Strike!"와 "Out!"을 새로 만들었습니다.
- 스트라이크 6개, 아웃 3개를 만들어 seed 101과 seed 34를 골랐습니다. seed는 같은 결과를 다시 만들 때 쓰는 번호입니다.
- 최종 길이는 스트라이크 0.733초, 아웃 0.677초, 세이프 0.675초입니다. 세이프와의 평균 음량 차이는 약 1.9\~2.8dB 이내입니다.

**왜** 사용자가 세이프는 비교적 괜찮다고 했습니다. 기존 녹음을 더 잘라내는 방식은 단어 경계가 붙어 발음이 어색해서 제외했습니다.

**실수·고칠 점**

- 자동 음성 인식이 세이프를 "SAVE!"로 잘못 알아들었습니다. 자동 인식을 정확한 발음 판정으로 쓰지 않았습니다.

### 게임 적용 (04:11)

**무엇이 바뀌었나** 사용자 요청으로 25개 음원을 게임에 연결했습니다. 원본을 다시 압축하거나 음높이를 바꾸지 않은 복사본입니다. 연결 규칙은 [F27](../../구현/해체해라-2026-10-07-v01/문서/SPEC-기능별-2026-10-07-v01/F27-상황별-사운드.md)에 있습니다.

- 처음 클릭하거나 키를 누른 뒤 소리가 시작됩니다(브라우저 자동재생 제한).
- 배경음악은 기본 30%, 효과음·목소리는 85%이며 설정에서 따로 조절·저장합니다.
- 판정·인물 반응·결과 소리가 날 때 배경음악을 평소의 24%로 낮춥니다.
- 판정음은 한 번에 하나만 냅니다. 0.76초 안에 여러 베이스 판정이 몰리면 아웃을 먼저 냅니다. 삼진은 스트라이크 → 0.82초 뒤 아웃입니다.
- 1·2·3배속 모두 애니메이션 진행에 맞춰 소리를 시작하고, 목소리와 타격음의 음높이는 바꾸지 않습니다.
- 오디오를 불러오지 못해도 경기 계산과 저장은 계속됩니다.
- 넣지 않은 것(manifest): 이전 스트라이크·아웃·세이프 변형, 보류한 불꽃놀이, 비교용 이어 듣기 파일, 이전 합성 투구·헛스윙.

**왜** 사용자가 "최신본 파일·GitHub 저장 및 게임 적용"을 요청했습니다.

**실수·고칠 점**

- 스트라이크·아웃은 요청에 따라 최신 시안을 넣었을 뿐, 사용자가 음색까지 최종 확정한 것은 아닙니다(적용본 README).

### v10 · 경기 입장 관중 웅성거림 (07:58)
