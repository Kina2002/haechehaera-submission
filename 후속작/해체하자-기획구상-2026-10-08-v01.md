# 해체하자 · 후속작 기획 구상

**작성일:** 2026-10-08

**상태:** 초기 구상 · 미구현

**위치:** 「해체해라」 후속작을 위한 별도 게임 기획

## 구상이 나온 계기

「해체해라」 발표 중 받은 피드백을 계기로, 유저 개인이 직접 야구 선수가 되는 후속작 「해체하자」를 구상했습니다.

이 문서는 후속작의 방향을 보관합니다. 현재 「해체해라」의 기능 추가 목록과는 별도로 관리합니다.

## 한 줄 소개

**각자 한 명의 야구 선수가 되어, 뜻대로 움직이지 않는 몸으로 함께 야구를 하는 병맛 협동 게임.**

서로 도와야 플레이가 이어지는데, 도와주려던 행동이 또 다른 사고를 만드는 재미를 지향합니다. 목표한 감정은 **협동 + 킹받음 + 함께 웃게 되는 어이없음**입니다.

## 사용자가 정한 핵심 방향

| 항목 | 방향 |
| --- | --- |
| 제목 | 해체하자 |
| 유저의 역할 | 개인이 선수가 되어 직접 플레이 |
| 분위기 | 조금 병맛인 야구 게임 |
| 조작감의 참고 | 「휴먼 폴 플랫」에서 느껴지는 조작감과 열받는 느낌 |
| 함께하는 재미 | 협동과 킹받음이 함께 나오는 플레이 |
| 기획 상태 | 추후 후속작 구상으로 보관 |

참고작에 대한 언급은 원하는 감각을 설명하기 위한 것입니다. 구체적인 조작 방식·캐릭터·화면 구성은 아직 정하지 않았습니다.

## 플레이 감각을 구체화하는 제안

아래 내용은 핵심 방향을 풀어 쓴 **후속 논의용 제안**이며, 확정된 구현 명세는 아닙니다.

### 내 몸을 잘 다루는 것도 야구 실력

공에 배트를 맞히고, 공을 집고, 동료에게 던지고, 베이스까지 달리는 행동을 유저가 직접 조작합니다. 몸의 균형이나 행동의 타이밍을 맞추는 과정에서 우스운 실패가 생기는 방향을 검토합니다.

반복해서 플레이하면 조금씩 잘 다룰 수 있어야 합니다. 실패했을 때에도 어떤 행동 때문에 꼬였는지 화면에서 알아볼 수 있는 조작감을 목표로 합니다.

### 협동이 필요해서 더 열받는 순간

내 행동이 동료의 다음 행동으로 이어집니다. 공을 잡은 사람과 송구를 받을 사람, 타격하는 사람과 달리는 사람이 서로 맞춰야 하는 상황에서 재미를 찾습니다.

잘 맞으면 멋진 팀플레이가 되고, 엇갈리면 모두가 사고를 수습하느라 바빠지는 흐름입니다. 누군가 실수했을 때 동료가 만회할 기회도 있으면 좋겠습니다.

### 야구 상황 예시

| 상황 | 검토할 장면 | 기대하는 재미 |
| --- | --- | --- |
| 타격 | 배트를 크게 휘두르다가 몸까지 돌아가 균형을 잃음 | 공을 맞히려던 진지함과 우스운 결과 |
| 뜬공 수비 | 두 선수가 같은 공을 잡으러 달려왔다가 서로 엉킴 | “내가 잡는다니까!” 하는 협동의 엇박자 |
| 중계 송구 | 공을 전달하려는데 받을 사람이 자세를 못 잡고 허둥댐 | 서로 준비를 맞춰야 하는 긴장감 |
| 주루 | 베이스에 도착하려다 넘어지고 다시 몸을 일으킴 | 조작 실수 뒤에도 끝까지 수습하는 순간 |
| 실수 만회 | 놓친 공을 다른 선수가 겨우 건져 다음 플레이를 이어감 | 사고가 팀의 이야기로 바뀌는 성취감 |

이 장면들은 분위기를 설명하는 후보입니다. 실제 행동과 판정은 작은 시험판에서 조작해 본 뒤 결정합니다.

## 먼저 시험해 볼 구상

짧은 협동 장면 하나로 **투구 → 타격 → 공 잡기 → 송구 → 주루**가 이어지는 경험을 확인하는 방안을 검토합니다.

확인하고 싶은 것은 조작이 우스운 장면을 만드는지, 함께 맞췄을 때 성공이 기쁜지, 실패 후 한 번 더 해보고 싶은지입니다. 정식 경기의 전체 규칙과 성장 시스템은 이 감각을 확인한 뒤 논의합니다.

## 아직 정하지 않은 사항

- 한 팀의 플레이 인원과 유저가 맡을 포지션
- 한 경기의 길이와 적용할 야구 규칙
- 같은 기기에서 함께할지, 온라인으로 함께할지
- 상대 팀을 다른 유저가 맡을지, 컴퓨터가 맡을지
- 시점, 이동·팔·배트·공의 구체적인 조작 방식
- 몸과 공의 움직임을 구현하는 방식과 조작 난이도
- 혼자 플레이할 수 있는 방식
- 능력치·성장·외형 꾸미기와 기존 게임 설정을 이어갈 범위
- 개발 도구, 실행 환경, 제작 일정
