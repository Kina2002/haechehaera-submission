# 해체해라 새 버전 재설계

**시작일: 2026-11-18 · 상태: 방향 기록, 구현 전**

## 사용자가 정한 전환

- 지금까지 만든 것을 [1차 MVP](../../기획참고/1차-MVP-2026-11-18-v01/README.md)로 기록합니다.
- 기능이 추가되며 화면이 복잡해졌고 부분 수정에 시간이 많이 들어, 새로 설계합니다.
- 현재 공개 버전 28과 기존 작업 자료는 비교·참고 기준으로 보존합니다.

## 다음 대화에서 검토할 제안

먼저 **경기 준비 → 경기 관전·지시 → 결과 확인**이라는 한 번의 플레이 흐름을 단순하게 만듭니다. 이는 화면을 정확히 세 장으로 고정하거나 운영 기능을 삭제한다는 결정이 아닙니다.

| 흐름 | 먼저 정할 질문 | 설계할 것 |
|---|---|---|
| 경기 준비 | 경기 시작 전에 꼭 결정해야 하는 것은 무엇인가? | 핵심 행동과 필요한 선수 정보 |
| 경기 중 | 지금 볼 것과 지금 누를 것은 무엇인가? | 경기장, 필수 점수·상황, 지시가 필요한 순간, 상세 정보 펼치기 |
| 경기 후 | 결과를 보고 무엇을 이해하고 다음에 무엇을 할까? | 주요 결과·선수 변화·다음 행동 |

각 흐름의 기본 화면과 상세 화면을 먼저 비교합니다. 이후 기존 기능을 ‘초기에 필요 / 상세 화면에서 제공 / 다음 단계에서 검토’로 분류하고 최소 범위를 사용자와 정합니다. 현재 MVP의 문서에 기능이 있다는 이유만으로 새 버전의 필수 요구사항으로 확정하지 않습니다.

## 이후 구현의 검토 기준 — 제안

- 주요 행동과 점수·경기 상황을 처음 보는 사람도 찾을 수 있어야 합니다.
- 선수 움직임과 공을 읽을 수 있는 공간을 우선 확보합니다.
- 상세 정보와 조작은 필요한 순간과 위치를 정해 표시합니다.
- 작은 범위의 흐름을 실제로 써 본 뒤 기능을 늘립니다.
- 그림·파츠의 재사용 여부와 경기 규칙의 재사용 여부를 각각 검토합니다.

## 아직 정하지 않은 것

새 버전의 기능 수, 메뉴·화면 구성, 캐릭터·경기장 자산의 채택 범위, 기술 구조, 저장 데이터 호환, 공개 주소와 교체 시점은 미정입니다. 이 문서는 대화 출발점이며 구현 승인이 완료된 명세가 아닙니다.

`후속작/`의 「해체하자」는 개인 선수가 되는 별도 협동 게임 구상입니다. 이번 문서는 기존 구단 운영 게임 「해체해라」의 재설계를 다룹니다.
