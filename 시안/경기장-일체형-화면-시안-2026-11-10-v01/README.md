# 경기장 일체형 정보 배치 · 그림 시안 v01

사용자 요청에 따라 실제 화면 구현에 앞서 **정지 시안 그림 한 장만** 만들었습니다.

**[PNG 원본](경기장-전광판-정보배치-시안-v01.png)** · [생성 요청문](생성요청문-v01.txt)

- 경기장이 화면 전체를 채우고, 외부 상단/우측/하단 정보 칸을 없앤 배치입니다.
- 경기장 안의 물리 전광판에 점수판과 현재 공격 팀9명 라인업을 함께 표시합니다.
- 홈 주변 좌우의 빈 잔디에 현재 타자·투수 정보를 작게 올립니다.
- 타석 선수 왼편에 풀스윙·컨택·참기 판단 버튼을 작게 둡니다.
- 낮은 공격 시점과1·3루가 보이는 구도, 기존 초록 유니폼의 빈 얼굴 뼈대 캐릭터를 참고했습니다.

OpenAI 내장 `imagegen`의 스크린샷 참조 생성으로 만든 UI 구도 제안입니다. 참조한 실제 배치 화면을 바탕으로 새 그림을 생성한 것이므로, 픽셀 단위 동일한 캡처나 작동하는 UI가 아닙니다. 글자·정보 밀도·플레이 중 가림과 수비 구도는 실제 적용 전에 별도로 확인해야 합니다. 사용자가 최신 메시지에서 '우선 시안 그림만'으로 범위를 한정했으므로 HTML·게임 원본·기존 미리보기·배포는 수정하지 않았습니다.
