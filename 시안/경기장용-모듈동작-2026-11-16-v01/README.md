## 머리와 몸 규격

정면 빈 머리는 [기존 보통형 머리 원본](../경기장용-6체형-머리몸분리-네자세-2026-11-16-v01/공통머리-4자세-보통형원본.png)을 재사용합니다. 새 옆·뒤 머리와 파츠는 이 머리에 맞췄습니다. 머리카락이나 얼굴을 몸 그림에 굽지 않습니다.

표시 칸64×64, 발 기준57(마지막 불투명 픽셀56), 머리 합성 칸25×24. 체형 내 몸 배율은 공통이며 체형별 기존 목→발 길이를 기준으로 합니다. 보통형 맨머리 기준 약40px; 다른 체형의 상대 키 차이를 유지합니다. 모자까지 포함해 실제40px로 표시할 때는 모든 체형에 같은 화면 배율을 적용합니다.

기존 저장 체형 번호는 바꾸지 않습니다: 0작은형 / 1키큰형 / 2보통형 / 3어깨넓은형 / 4날렵형(이전 둥근형 번호) / 5중량형. 중량형은 튀어나온 배를 제외하고 두꺼운 가슴·팔·허벅지로 구별합니다. 어깨형은 넓은 어깨와 좁은 허리입니다.

[배치 자료](에셋-배치자료-v01.json)에 원본 크기·해시 이름·각 칸의 crop/목/발 위치를 기록했습니다. 원본 PNG는 보존하고 게임 렌더러가 연결된 몸 영역을 고른 뒤 정수 격자·최근접 방식으로 표시합니다. 생성 원본의 이웃 칸 침범과 반투명 점을 화면에서 제외하며, 손이 작은 점으로 끊어지지 않게 원본 해상도에서 먼저 연결 영역을 고릅니다.

- 피부·머리·눈동자색은 선수의 기존 appearance를 사용합니다. 얼굴·귀·목·팔·손의 피부 팔레트 공유, 흰자와 장비는 유지합니다. [팔 피부6색 진단](피부색-잔여픽셀-진단-v01.json).

- 배트는 손잡이가 맞는 몸 프레임에 포함합니다. 배트를 놓은 뒤의 장면 소품은 별도 표시합니다. 글러브·포수 마스크·보호대는 v02 파츠를 실제 경기의 손·몸 위치에 연결했습니다.
