# 중계 집중형 · 공격/수비 카메라 시안 v02

- 참가자가 선택한 방향: **공격은 홈 뒤에서 가깝게, 수비는 높은 곳에서 넓게**.
- 공격 준비/투구: 타자·투수와 1·3루가 보이는 근접 구도. 2루와 외야는 화면 밖이며 상단 주자 표시를 유지합니다.
- 공격 중 타구 발생: 화면을 부드럽게 넓혀 타구·주루·수비를 봅니다. 플레이 결과 뒤 다음 투구 준비 때 근접 구도로 돌아옵니다.
- 수비: 외야와 내야 전체가 보이는 넓은 구도를 유지합니다.
- `공수 시점 ON/OFF`로 카메라 차이를 비교합니다. 경기장 위의 안내 글로 현재 구도를 확인합니다.
- 기존 2D 경기장 그림의 카메라 범위를 바꾼 시안입니다. 원근이나 경기장 각도를 새로 그린 결과는 아닙니다.
- 점수판·공격 팀 타순·하단 지시 버튼은 v01의 위치를 유지합니다. v01 파일은 보존했습니다.

- 기존 게임의 경기장·선수·시뮬레이션을 그대로 불러오는 독립 미리보기입니다.
- 위: 7이닝 점수판(R/H/E), 볼·스트라이크·아웃, 경기 진행 버튼.
- 가운데: 넓어진 경기장, 오른쪽에는 **현재 공격 팀 9명**만 표시. 현재 타자는 노란색으로 강조합니다.
- 아래: 현재 타자 / 지시 버튼 / 현재 투수. 경기장 안의 움직임을 가리지 않습니다.
- `우리 공격`, `우리 수비`는 장면 확인용이며, `움직임 보기`로 실제 자동 경기를 볼 수 있습니다.
- 정지 장면의 3회 2:1 점수와 주자 배치는 구도 확인을 위한 예시입니다.
- `현재 화면`으로 기존 배치와 비교할 수 있습니다. `경기 기록`은 필요할 때 열며 타순은 유지됩니다.
- 캐릭터 리디자인을 적용한 결과가 아닙니다. 현재 게임 리소스를 사용합니다.

## 실행

`deployment-output/중계-집중형-실제게임-시안-2026-11-09-v02.html`을 브라우저에서 열면 인터넷 없이 실행됩니다.

개발용으로는 저장소 루트에 HTTP 서버를 열고 이 폴더의 `index.html`에 접속합니다.

빌드: `python build-single.py` (이미 존재하는 결과를 보존하려면 다른 출력 파일 경로를 지정하세요.)

`data-test-session`이 켜져 있어 실제 구단 저장을 읽거나 쓰지 않습니다. `구현/` 원본 파일을 수정하지 않았으며 실제 배포에도 반영하지 않았습니다.
