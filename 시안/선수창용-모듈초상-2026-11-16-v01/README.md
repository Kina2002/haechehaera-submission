# 선수창용 모듈 초상 · 2026-11-16 v01

사용자 목표: 체크리스트 순서에 따라 제작, 큰 묶음별 자체 검수·수정, 마지막 실제 사이트 적용과 연속 동작 확인까지 진행한다. 이번 폴더는 첫 묶음의 제작·로컬 적용 결과다. 공개 사이트 배포 완료 기록은 아니다.

## 표시 기준

- 선수창은 자연스러운 성인 비례의 상세 도트 **상반신 초상**. 경기장용 작은 전신 비례와 분리한다.
- 원본 참고는 [상세 도트 보통형](../캐릭터-리디자인-시안-2026-11-09-v01/이미지도구/선수창용-상세도트-보통형-v01.png). 기존 게임·만화 인물의 얼굴을 복제하지 않은 새 파츠를 만들었다.
- 128×160 논리 픽셀에서 파츠를 한 번 합성한다. 확대·축소는 최근접 픽셀 표시를 쓴다. 작은 카드에는 같은 합성 결과의 얼굴 부분을 표시한다.
- 머리1개, 상반신6개, 눈·눈썹·코·입 각6개, 머리카락7개, 수염5개, 안경/선글라스6개, 아이블랙3개, 모자·헬멧·아이패치 각1개. 장비는 별도 그림이다. 모자/헬멧/아이패치는 현재 미리보기 선택 가능하며 기존 저장 선수에게 임의 추가하지 않았다.
- 기존 appearance의 body/skin/hairColor/eyeColor/parts 선택값을 재사용한다. 같은 체형·성격을 같은 얼굴로 고정하지 않는다. 체형 ID는 기존 순서인 작은0·키큰1·보통2·어깨3·날렵4·중량5. 기존 둥근형4는 새 체형 합의에 따라 날렵형으로 표시한다.
- 피부는 얼굴·귀·목·코·팔에서 같은 6색 팔레트를 사용한다. 눈동자는 별도 색 판정으로 6색을 적용하며 흰자와 동공을 유지한다. 머리/수염/눈썹은 머리색7종을 공유한다.
- 체형은 어깨·가슴·팔의 차이로 표시하며 선수창 초상의 전체 높이로 신장을 표현하지 않는다. 경기장 전신의 상대 키 차이는 기존 기준을 유지한다.

## 원본과 보정

- 제작 도구: 내장 GPT image_gen. [생성 요청문](생성요청문.json), [보정 요청문](보정요청문.json).
- 머리와 몸, 각 얼굴/머리/장비 원본 PNG는 분리되어 있다. 게임은 [배치 자료](에셋-배치자료-v01.json)로 필요한 부분을 읽는다.
- 상반신 v01/v02는 소매 아래 팔이 없어 옷만 떠 보였다. v03에서 가슴 높이의 초상으로 자르고 팔을 추가했다. v01/v02는 검토 이력으로만 보존한다.
- 실제 표시에서 어두운 피부의 팔 하이라이트가 흰색으로 남는 문제를 발견해 피부 영역 판정을 수정했다. [수정 뒤 피부6색](피부6색-팔연결-v02.png).
- 키큰형 영역에 이웃 체형의 픽셀이 들어와, 연결된 주 몸통 덩어리로 경계를 측정해 제외했다. 원본 PNG를 고쳐 덮어쓰지는 않았다.
- 최종 게임 표시는 논리 픽셀에서 알파를 0/255로 정리하고 색 단계를 제한한다. 원본 파일에 남은 미세한 투명 가장자리를 그대로 확대하지 않는다.

## 아직 연결할 항목

선수창과 경기장 사이의 동일 인물 확인(창03.2)은 새 경기장용 머리·파츠와 연결 후 마무리한다. 경기장용 동작·사이트 배포·모든 체형의 연속 동작 검수는 이 폴더 결과만으로 완료 처리하지 않는다.

원본 및 시안 폴더를 보존하며 구현은 별도 작업트리에서 진행 중이다. 단일 HTML은 새 이미지 추가로 용량이 커져 최종 배포 단계에서 전달 방식을 함께 정리한다. 사이트는 기존처럼 dev.html과 src/assets로 배포한다.
