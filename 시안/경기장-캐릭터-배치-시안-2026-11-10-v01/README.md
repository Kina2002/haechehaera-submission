## 이번 배치의 범위

- 새 그림을 다시 생성하거나 원본 PNG를 수정하지 않았습니다. 각 체형을 해당 영역에서 잘라 Canvas에 그립니다. 원본의 체형별 키 차이는 공통 배율로 유지합니다.
- 6체형이 모두 보이도록 예시 포지션에 임시 할당했습니다. 체형과 포지션·성격·능력치를 연결하는 게임 규칙을 정한 것은 아닙니다.
- 머리카락·모자·눈코입이 없는 현재 뼈대 상태입니다. **모두 정면 서기 그림**이며 타격·투구·포수의 쪼그림·뒤/옆 방향은 적용 전입니다. 포수도 서 있으므로 낮은 화면에서 보이는 포수의 최종 높이·가림을 판단할 수는 없습니다.
- 두 팀 모두 원본의 공통 초록 유니폼과 임시 피부색을 사용합니다. 팀 색과 피부·눈동자 색 변경을 구현한 시안은 아닙니다. 심판과 하단 선수창은 기존 그림입니다.
- 공격은 가까운 타자/포수가 크게 보이고 외야 선수는 원근 때문에 작게 보입니다. 수비 전체 구도에서는 선수 간격과 체격 차이를 함께 볼 수 있습니다.
- 원본 게임 `구현/`과 기존 경기장 v04 파일은 변경하지 않았습니다. `data-test-session`에서 예시 경기만 사용하며 실제 구단 저장과 연결하지 않습니다. 실제 배포에는 반영하지 않았습니다.

`공격-새캐릭터-배치-v01.png`와 먼저 만든 `deployment-output/경기장-캐릭터-배치-시안-2026-11-10-v01.html`은 초기 배치 이력입니다. 현재 비교는 위의 공격v02·수비v01 및 '배치-미리보기' HTML을 사용합니다.
