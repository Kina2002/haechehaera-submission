# 경기 입장 관중 웅성거림

사용자가 미리 듣고 적용을 승인한 5.4초 효과음입니다. 관중 입장 → 선수 준비 → 경기 시작 연출에 사용합니다.

- [적용 MP3](audio/entrance-crowd-murmur.mp3)
- 원본: [trezz77 — Crowd talking / murmur](https://freesound.org/people/trezz77/sounds/546676/)
- 출처 라이선스: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). 2026-10-08 원작자 페이지에서 확인했습니다.
- Freesound가 제공하는 공개 고음질 미리듣기 MP3를 `sources/`에 보관했습니다. 원본 녹음은 큰 극장 로비의 대화 소리이며 구장 현장 녹음은 아닙니다.
- 편집: 원본 12초부터 5.4초 사용, 140Hz 고역통과·3800Hz 저역통과, 피크 제한 0.75, 처음 0.3초 페이드인·마지막 0.85초 페이드아웃, 44.1kHz 스테레오 MP3 160kbps.
- 검사: 디코딩 5.4초, 평균 -22.8dBFS, 최대 -6.8dBFS. 원본 및 결과 해시는 `source.json`에 기록합니다.

FFmpeg 재생성 명령은 `make_audio.py`에 있습니다. 게임 복사본과 연결 정보는 `사운드/최신-적용본-2026-10-08-v01/manifest.json`을 기준으로 합니다.
