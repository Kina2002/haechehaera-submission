# 승부처 개입 시안 · 2026-11-05 v01

자동 경기로 구경하다가 **승부처에서만 경기가 멈추고 감독에게 지시를 묻는** 방식의 시안입니다. 실제 게임 화면·선수 그림·규칙 위에 이 기능만 덧붙였습니다.

- 게임 원본 파일(`구현/해체해라-2026-10-07-v01/`)은 바꾸지 않았습니다.
- 시험 모드로 실행되어 실제 구단 저장을 읽거나 쓰지 않습니다. 시험용 구단이 매번 새로 만들어집니다.
- 아직 실제 게임에 적용하지 않은 시안입니다.

## 여는 방법

**두 번 클릭으로 열기:** `deployment-output/승부처-개입-시안-2026-11-05-v01.html`을 Chrome이나 Edge에서 엽니다. 그림과 글꼴이 모두 들어 있어 약 100MB이며 인터넷 연결이 필요 없습니다.

이 파일이 없거나 게임 코드를 바꾼 뒤 다시 만들려면 저장소 최상위 폴더에서 아래 명령을 실행합니다.

```text
python 시안/승부처-개입-시안-2026-11-05-v01/build-single.py
```

## 화면에서 해 볼 것

1. 열면 입장 연출 뒤 자동 경기가 시작되고, 곧 **득점 기회** 창이 뜹니다.
2. 오른쪽 아래 **승부처 개입 시안** 패널에서 다른 상황을 바로 볼 수 있습니다: 득점권 공격 · 위기 수비 · 끝내기 기회 · 투수 체력 바닥.
3. 창에서 하나를 고르면 그 지시가 실제 경기에 반영됩니다. 10초 동안 고르지 않으면 초록색 **자동 판단** 선택지대로 계속합니다.
4. 패널의 체크를 끄면 지금의 자동 경기처럼 멈추지 않습니다. 빈도는 **가끔**(4회 이후 1점 차 이내, 반 이닝에 한 번)과 **자주**(3회 이후 2점 차 이내, 타석마다) 중에서 고릅니다.

## 승부처와 선택지

| 승부처 | 언제 | 선택지 |
|---|---|---|
| 득점 기회 | 우리 공격 · 득점권 주자 · 접전 · 후반 | 풀스윙 / 컨택 / 참아 / 도루(가능할 때) |
| 끝내기 기회 | 5회 이후 말 공격 · 동점이나 1점 뒤짐 · 주자 있음 | 위와 같음 |
| 실점 위기 | 상대 공격 · 득점권 주자 · 접전 · 후반 | 전진 / 기본 / 후퇴 수비 |
| 투수 체력 바닥 | 우리 투수 체력 30% 이하 | 투수 교체(교체 창) / 계속 던지기 · 10초가 지나면 후보 중 체력과 투구 능력이 가장 좋은 투수로 자동 교체 |

공격 지시는 그 타석이 끝날 때까지 유지되고, 수비 지시는 다음 타자 전에 다시 정해집니다.

## 이 시안에 없는 것

- 번트·고의4구: 현재 게임 규칙에 아직 없어서 선택지에 넣지 않았습니다.
- 설정 저장: 켜기·끄기와 빈도는 시안을 다시 열면 처음 값으로 돌아갑니다.
- 반자동 경기: 반자동은 이미 공마다 지시를 받으므로 승부처 창을 띄우지 않습니다.
