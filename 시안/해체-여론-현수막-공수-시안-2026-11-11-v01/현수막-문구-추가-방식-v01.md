## 재사용할 것과 추가할 것

천 그림과 문구를 분리합니다. 짧은형·넓은형 등 빈 도트 천 소품을 재사용하고, 글자는 게임에서 따로 그립니다. 문구가 늘어날 때마다 천 이미지를 새로 생성하지 않습니다.

이번 비교 PNG는 천과 글자가 합쳐진 정지 그림입니다. 이 파일 자체가 문구 교체용 자산은 아닙니다. 빈 천 파츠·글자 표시 기능·문구 목록 연결은 실제 구현 때 제작합니다.

## 문구 목록의 항목

아래 항목은 구현을 위한 제안 형식입니다. 실제 저장 파일명이나 프로그램은 아직 만들지 않았습니다.

| 항목 | 기록할 내용 |
| --- | --- |
| 고유번호 | 문구마다 중복 없는 이름. 예: banner-calm-001 |
| 문장 | 화면에 보여줄 정확한 문구 |
| 여론 단계 | 평온 / 술렁임 / 분노 / 해체 직전 |
| 권장 천 | 짧은형 또는 넓은형 |
| 줄바꿈 | 필요한 경우 허용할 단어 사이의 위치 |
| 사용 여부 | 새 경기의 후보로 사용할지 |

추가 예: 고유번호 banner-calm-001, 문장 “오늘도 직관 성공”, 단계 평온, 권장 천 넓은형, 한 줄.

새 문구는 새 고유번호로 덧붙입니다. 기존 번호를 다시 매기거나 다른 문구에 재사용하지 않습니다. 더 쓰지 않을 문구는 사용 여부를 끄는 방법을 우선합니다. 기존74개 후보 전체의 표현을 이번 디자인 승인만으로 확정한 것으로 보지는 않습니다.

## 긴 문구를 넣는 순서

1. 현수막의 글자 영역과 실제 사용할 글꼴로 문장의 폭을 확인합니다. 단순 글자 수만으로 잘 맞는다고 판단하지 않습니다.
2. 한 줄에 들어가지 않으면 단어 사이에서 최대2줄로 나눕니다.
3. 작은 천에 들어가지 않으면 넓은 천과 그에 맞는 자리를 사용합니다.
4. 그래도 최소 글자 크기를 지킬 수 없으면 더 짧은 문구로 다듬은 뒤 추가합니다. 글자를 끝없이 줄이거나 문장 끝을 잘라 숨기지 않습니다.

글자 영역의 여백·최소 크기와 천의 실제 픽셀 크기는 실제 공수 화면 크기에서 정합니다. 아직 시험하지 않은 숫자를 고정 기준으로 적지 않습니다. 짧은 문구, 공백 포함 긴 문구, 두 줄 문구, 한글·숫자·문장부호를 함께 확인합니다.

## 경기에서 고르고 유지하기

- 여론 계산은 [P09](../../구현/해체해라-2026-10-07-v01/문서/SPEC-기능별-2026-10-07-v01/P09-시즌-리그-해체여론.md)의 단계 값을 받아 사용합니다. 현수막용 별도 여론 계산을 만들지 않습니다.
- 경기 시작 때 해당 단계의 사용 가능한 후보에서 중복 없이 문구를 고릅니다. 후보가 부족하면 같은 문구로 억지로 채우지 않고 걸리는 수를 줄입니다.
- 단계별 개수는 기존 문구 문서의 평온1~2 / 술렁임1~2 / 분노3~4 / 해체 직전5~6을 초기안으로 사용합니다. 이번 채택 시안은 평온2장과 해체 직전6장을 비교한 것입니다.
- 문구 고유번호·당시 문장·천 종류·난간 자리 번호를 경기 자료에 함께 저장합니다. 공수 전환과 새로고침마다 다시 뽑지 않습니다. 이후 목록을 편집해도 진행 중 경기나 다시 보기의 문구가 바뀌지 않게 합니다.
- 경기 뒤 여론이 변하면 다음 경기의 문구와 개수에 반영합니다.
- 경기장 안 같은 난간 자리를 공수 카메라의 원근에 맞춰 표시합니다. 화면 좌표만 따로 정해 공수 전환 때 다른 장소로 이동한 것처럼 보이지 않게 합니다.

## 배치와 홈·원정

전광판 양옆 관중석 난간에 최대6곳을 둡니다. 시안에서는 좌우 각각 작은2곳+넓은1곳이며, 평온은 아래쪽 넓은2곳만 사용했습니다. 타구·주자·야수·심판·점수·현재 공격 라인업·얼굴 포함 선수정보·조작부·판단·작은 경기 기록을 가리지 않아야 합니다.

현수막은 우리 팬의 표현입니다. 홈에서는 우리 응원석을, 원정에서는 따라온 우리 팬 구역을 사용합니다. 원정 관객0명이면 우리 현수막도 생략합니다. 이번 그림은 홈경기 예시이며 원정의 자리와 수 제한은 별도 화면에서 확인해야 합니다.

## 실제 적용 때 확인할 것

- 신규 문구 하나를 목록에만 추가해 이미지 재생성 없이 표시되는가.
- 두 카메라와 실제 표시 크기에서 줄바꿈·문장부호·글자가 읽히는가.
- 후보 수가 적거나 긴 문구만 있을 때 중복·잘림·겹침을 피하는가.
- 공수 전환·새로고침·과거 경기 다시 보기에서 당시 선택이 유지되는가.
- 원정 관객0명일 때 현수막이 나오지 않는가.

위 항목은 앞으로 확인할 기준입니다. 이번 기록 작업에서 기능을 구현하거나 자동 검사를 완료했다는 뜻은 아닙니다.
