# 수비 준비 뼈대·파츠 시안 — 2026-11-17

기존 F24의 대기 홈 방향 규칙에 사용할 **수비 준비 자세**를 추가했습니다. 서기/리드의 재사용과 구별한 새 그림입니다. 기존 머리 비율과 파츠 좌표는 유지합니다.

## 만들어진 것

- 보통·작은·키큰·어깨넓은·날렵·중량 **6체형 × 정면/오른쪽 반측면/왼쪽 반측면 = 18자세**.
- 각 자세의 머리 없는 몸, 앞팔, 글러브 PNG. 왼쪽 몸은 오른쪽 완성 그림을 뒤집지 않고 생성 원본의 왼쪽 자세에서 따로 추출했습니다.
- 피부·주색·부색·바지·신발·글러브 재질 영역. 바지는 흰색, 신발과 글러브는 독립 색입니다.
- 기존 F/FR/FL 머리·눈코입·눈썹·헤어·모자·안경·아이블랙·귀걸이·목걸이 연결. 이 방향의 머리 파츠는 이미 있어 새로 그리지 않았습니다.
- 보완한 장비는 자세별 새 글러브입니다. 팔의 갈색 그림자가 글러브에 섞이지 않게 분리했습니다.

이번 그림은 **오른손 송구·왼손 글러브** 세트입니다. 바라보는 방향과 글러브 손은 다른 속성이며, 좌타/우타만 보고 글러브를 바꾸지 않습니다. 왼손 송구 세트의 미술 검토와 별도 연결은 후속입니다.

## 연결 규칙

전신64×64, 발 기준y56, 머리33×36의 목 기준(16,24)을 유지합니다. 자세별 `neck`와 `headPosition`은 poses.json에 있습니다. 보통·중량 목y35, 작은형y39, 키큰형y32, 어깨넓은·날렵형y34입니다.

**뒤머리 → 몸 → 목걸이 → 얼굴 → 안경/귀걸이/아이블랙 → 앞머리 → 모자 → 장비 위 머리 → 앞팔 → 글러브** 순서입니다. 앞팔은 몸의 해당 픽셀을 반복해서 위에 얹는 가림용 레이어입니다. 글러브 아래 가려진 부분은 별도로 복원한 맨손 자세가 아니므로 이 포즈에서는 글러브 레이어를 함께 사용합니다.

몸의 피부 재질1~5는 기존 머리 피부 팔레트와 동일합니다. 주색50~53, 부색60~62, 바지70~73, 신발80~82, 글러브90~93은 이번 몸 파츠의 재질 번호입니다. 기존 머리 재질 번호40~43과 혼용하지 않습니다. `compose.cjs`는 기존 경기장 파츠 폴더를 참조하는 제작용 예제이며, HTML 검수기는 외부 파일 없이 동작합니다.

주색은 상의/양말/모자 몸통, 부색은 옷깃/소매 끝/모자 챙입니다. 얼굴·머리·눈썹·홍채는 기존 파츠의 색 규칙을 따릅니다. 완성 캐릭터 전체를 좌우 반전하지 않습니다.
