# 중계 화면 시안 · 2026-11-09 v01

경기 화면을 TV 야구 중계처럼 바꾸는 시안입니다. **경기장을 화면 가득 깔고, 정보는 경기장 위 모서리에 작게 띄웁니다.** 버튼 하나로 **새 화면 / 지금 화면**을 바꿔 비교할 수 있습니다.

- 게임 원본 파일(`구현/해체해라-2026-10-07-v01/`)은 바꾸지 않았습니다. 게임 부품을 지우지 않고 자리만 옮깁니다.
- 시험 모드로 실행되어 실제 구단 저장을 읽거나 쓰지 않습니다.
- 아직 실제 게임에 적용하지 않은 시안입니다.

## 여는 방법
`deployment-output/중계-화면-시안-2026-11-09-v01.html`을 Chrome이나 Edge에서 두 번 클릭해 엽니다. 파일 크기는 약 100MB이고 인터넷 연결이 필요 없습니다. 입장 연출 뒤 자동 경기가 시작됩니다.

다시 만들려면 저장소 최상위 폴더에서 아래 명령을 실행합니다.

```text
python 시안/중계-화면-시안-2026-11-09-v01/build-single.py
```

## 바뀐 배치
| 위치 | 무엇 |
|---|---|
| 화면 전체 | 경기장. 관중석은 위쪽 띠만 남기고 잘라냈습니다. 화면 크기에 맞춰 관중석을 자르는 정도가 자동으로 바뀝니다 |
| 왼쪽 위 | 점수 표시(팀·점수·이닝·볼·스트라이크·아웃·주자) |
| 위 가운데(관중석 띠 위) | 조작 줄(소리, 선수 교체, 남은 경기 스킵, 자동 경기, 배속, 일시정지, 반자동) |
| 오른쪽 위 | **라인업**, **경기 기록** 버튼. 누르면 오른쪽에 열립니다 |
| 왼쪽 아래(빈 파울 지역) | 작전 버튼(반자동일 때 고르는 칸)과 우리 팀 현재 선수 카드 |
| 오른쪽 아래 | 상대 팀 현재 선수 카드 |
| 아래 가운데 | **비워 둠**. 홈플레이트(타자·포수·주심)가 있는 가장 중요한 자리라서 아무것도 올리지 않았습니다 |
| 이름표 | 타자 팀(주자), 투수, 공을 잡은 수비수만 보입니다. 맨 위 시안 버튼으로 "모두"로 바꿀 수 있습니다 |

## 공격 화면과 수비 화면 (2026-11-09 추가)
칸의 자리는 바꾸지 않고, 아래 세 가지만 달라집니다.

| | 우리 팀 공격 | 우리 팀 수비 |
|---|---|---|
| 카메라 | 홈플레이트 쪽으로 약 1.2배 가깝게(2루까지 보임). 공을 치면 천천히 넓어지며 공을 따라감 | 넓게. 수비수 9명과 수비 시프트가 한눈에 보임 |
| 점수 표시 위 | "우리 팀 공격"(우리 팀 색) | "우리 팀 수비"(파랑) |
| 카드 | 우리 타자 카드에 노란 테두리, 상대 투수 카드는 조금 작고 흐리게 | 우리 투수 카드에 노란 테두리, 상대 타자 카드는 조금 작고 흐리게 |

- 공수 교대 연출 중에는 넓은 화면으로 바뀝니다.
- 맨 위 시안 버튼의 **카메라: 공격 때 가깝게 / 항상 넓게**로 비교할 수 있습니다.
- 그림용 정지 장면: 주소 끝에 `?still=attack`(우리 팀 공격, 1·2루 주자) 또는 `?still=defense`(우리 팀 수비, 1루 주자)를 붙이면 그 장면에서 멈춥니다. `&mode=off`를 더하면 지금 화면으로 엽니다.

## 숫자로 본 차이 (1536×864 노트북 화면)
| | 지금 화면 | 새 화면 |
|---|---|---|
| 경기장 그림 | 화면의 약 48% | 화면의 약 97% |
| 그중 그라운드(관중석 제외) | 화면의 약 31% | 화면의 약 78% |
| 선수 크기 | 1배 | 약 1.7배 |
| 조작 버튼 | 스크롤해야 보임 | 항상 보임 |

## 화면에서 해 볼 것
1. 열면 자동 경기가 진행됩니다. 맨 위 가운데 **새 화면 / 지금 화면**을 번갈아 눌러 비교합니다.
2. 오른쪽 위 **라인업**, **경기 기록**을 눌러 봅니다.
3. 조작 줄의 **반자동으로**를 눌러, 왼쪽 아래 작전 버튼이 쓰기 편한지 봅니다.
4. 공수 교대, 선수 말풍선, 관중·중계 말풍선이 제자리에 나오는지 봅니다.

## 확인한 것
- 새 화면과 지금 화면을 오가도 오류가 없고, 지금 화면으로 돌아가면 원래 배치와 크기가 그대로입니다.
- 자동 경기에서 플레이 17번과 공수 교대 1번 동안 오류가 없었습니다. 게임이 화면을 다시 그릴 때마다 모서리 칸이 즉시 제자리로 돌아왔습니다. 선수 말풍선은 경기장 밖으로 나가지 않았습니다.

## 아직 하지 않은 것
- 결과 배너("2루타!"를 크게 잠깐 띄우기)는 게임의 기존 알림을 그대로 썼습니다.
- 공을 따라가는 부드러운 카메라 이동은 넣지 않았습니다.
- 휴대폰처럼 좁은 화면은 확인하지 않았습니다.
