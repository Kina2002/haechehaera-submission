# 경기장 일체형 · 공격/수비 전체정보 시안 v02

사용자는 경기장이 화면을 채우고 점수·라인업을 구장 전광판에 넣은 구성을 더 좋다고 평가했습니다. 이후 타자·투수 얼굴, 첨부한 조작부와 작은 경기 기록이 빠졌다고 지적했고 **공격·수비 모두 누락 없이 그림 시안으로** 보여달라고 요청했습니다. 이에 두 장을 만들었습니다.

- **[수비 시안](수비-전체정보-시안-v01.png)** · [수비 생성 요청문](수비-생성요청문-v01.txt)

## 두 그림에 포함한 항목

| 항목 | 공격 | 수비 |
| --- | --- | --- |
| 경기장 전체 화면 | 포수 뒤 낮은 시점·1/3루 포함 | 높은 전체 시점·내외야 전체 |
| 구장 안 물리 전광판 | 두 팀7이닝·R/H/E | 같은 표와 배치 |
| 현재 공격 팀9명 라인업 | 우리 팀·4번 타자 강조 | 상대 팀·3번 타자 강조 |
| 경기 상태 | 3회말·B/S/O·1/3루 주자 표시 | 3회초·B/S/O·1루 주자 표시 |
| 공통 조작 | 소리ON/OFF, 선수 교체, 자동 배속1배속, 경기 재개, 반자동으로 | 동일 |
| 잔디 위 현재 타자 정보 | 작은 얼굴·이름/등번호·능력치·체력 막대 | 상대 타자 작은 얼굴·이름/등번호·우타/파워·체력 막대 |
| 잔디 위 현재 투수 정보 | 작은 얼굴·이름/등번호·구속/제구/센스·체력 막대 | 우리 투수 작은 얼굴·이름/등번호·능력치·체력 막대 |
| 판단 지시 | 풀스윙·컨택·참기 | 기존 수비 위치9선택(후퇴/기본/전진 × 좌/중앙/우) |
| 기본 판단과 시간 | 작은 타이머·그대로 해 | 동일 |
| 작은 경기 기록 | 최근2줄·경기 기록+ | 동일 |

얼굴은 선수창용 초상이고 경기장 안 임시 뼈대와 구분합니다. 공간을 줄이기 위해 얼굴을 없애지 않고 정보칸 안에 작은 초상을 남기는 방향으로 고쳤습니다. 공격·수비에서 공통 정보와 조작은 같은 영역에 유지하고 카메라·공격 라인업·현재 선수·판단 지시를 바꿉니다.

## 제작과 현재 범위

OpenAI 내장 `imagegen`의 참조 이미지 기반 UI 그림 생성으로 만들었습니다. 이전 경기장 일체형 그림, 실제 공격/수비 배치 캡처, 사용자의 조작부 캡처를 참조했습니다. PNG 원본과 요청문, 조작부 참고 이미지를 새 폴더에 보관하고 이전 결과는 보존했습니다.

화면 요소의 포함과 배치를 육안으로 대조하고 PNG 무결성을 확인했습니다. **작동하는 게임 화면이나 실제 구현 캡처가 아닌 정지 구도 시안**입니다. 작은 글자·초상·선수 동작과 가림은 실제 제작에서 조정해야 합니다. 경기장 안 임시 뼈대의 얼굴/머리카락 파츠 작업을 완료한 결과가 아닙니다. HTML·게임 원본·기존 실행 미리보기·GitHub·배포는 변경하지 않았습니다.
