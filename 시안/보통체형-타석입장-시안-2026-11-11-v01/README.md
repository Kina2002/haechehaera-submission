# 보통 체형 · 타석 입장 시안

현재 선택본은 [단일 HTML v03](보통체형-타석입장-미리보기-v03.html)입니다. 팀과 흐름을 고르고 재생합니다. 홈팀은 화면 오른쪽, 원정팀은 화면 왼쪽에서 걸어옵니다. 경기장 안에 덕아웃 구조물을 추가하지 않습니다.

## 재생과 그림

| 구분 | 영상 | 입장 8단계 그림 |
| --- | --- | --- |
| 홈팀 · 오른쪽에서 | [MP4](보통형-타석입장-home-full-v01.mp4) | [PNG](home-sheet-v02.png) |
| 원정팀 · 왼쪽에서 | [MP4](보통형-타석입장-away-full-v01.mp4) | [PNG](away-sheet-v02.png) |

흐름은 **등장 → 배트 들고 걷기 → 감속 → 투수를 향해 몸 돌리기 → 발 위치 잡기 → 어깨 풀기/짧은 배트 움직임 → 배트 들기 → 준비 완료**입니다. `입장·준비만`과 `타격·1루까지`를 선택할 수 있습니다. 시간 막대, 단계 버튼, 0.5배 재생과 `준비 자세로` 생략 버튼도 있습니다.

홈팀은 오른쪽에서 포수·심판 앞쪽으로 돌아와 우타자석에 들어서고, 원정팀은 왼쪽에서 같은 타석으로 들어섭니다. 두 팀의 걷는 속도는 같고 이동 거리에 따라 입장 시간이 달라집니다. 준비 완료 때 기존 보통 체형의 준비 칸으로 연결하며, 이후에는 기존 타격·배트 놓기·출발·1루 세이프/베이스 대기 흐름을 재생합니다.

## 사용자가 고친 기준

최초 요청은 덕아웃 출발이었으나, 제작 중 사용자가 **경기장에 그린 덕아웃 구조물은 필요 없고 홈팀은 타석 오른쪽, 원정팀은 왼쪽에서 나오면 된다**고 수정했습니다. 캐릭터 이미지 제작을 취소한 뜻이 아니라는 설명도 반영했습니다.

새 캐릭터 분할 동작은 그대로 사용하고 경기장 배경은 [기존 낮은 공격 구도](경기장-낮은공격-배경-v01.png)를 그대로 복사했습니다. 구조물이 들어간 생성 배경은 현재 시안에 사용하지 않았습니다. [이전 덕아웃 기획](../타자-덕아웃-타석입장-동작기준-2026-11-11-v01.md)은 변경 전 기록입니다.

## 캐릭터와 재사용

[새 입장 24칸 원본](보통형-타석입장24칸-v01.png)은 **내장 GPT 이미지 도구**로 기존 새 보통형을 참조하여 생성했습니다. [생성 요청문과 선택 기록](생성-요청문.json)을 보관했습니다. 1536×1024, 6열×4행의 투명 PNG입니다. 계단 동작 0~2번은 변경된 연출에서 쓰지 않고, 배트가 빠진 18번도 선택하지 않습니다. 걷기·정렬·루틴·배트 들기 칸을 골라 연결합니다.

완료 자세는 [기존 보통형 동작 원본](보통형-동작24칸-v02.png)의 준비 칸을 사용해 기존 타격 흐름에 연결합니다. 최종 준비 직전에는 반투명한 두 몸이 겹치는 전환을 사용하지 않습니다. 입장 중 타격 지시 영역은 입장 안내로 표시하고, 기존 얼굴 포함 선수 정보·경기 기록·점수판·공격 라인업·현수막·심판은 유지합니다.

현재는 보통 체형 **우타자 한 명**의 기본 입장입니다. 홈/원정 모두 같은 임시 유니폼·피부색과 고정 예시 명단을 사용하므로 실제 팀 상태를 연결한 결과와 구분합니다. 머리카락·모자·눈코입, 선수별 피부/눈동자색 교체는 적용 전입니다. 좌타자 타자석 연결, 여러 개인 루틴과 최종 40px 격자 정리는 후속입니다.

## 확인한 내용

- [브라우저 검사](browser-checks-v01.json): 홈/원정 × 입장만/전체 흐름의 36개 시점에서 출발 쪽, 준비 위치/방향, 배트 없는 칸 제외와 오류 여부를 확인했습니다. 1536×706 화면에서 가로/세로 넘침이 없었습니다.
- [생략 버튼 검사](skip-check-v01.json): 입장 중 준비 완료 자세로 이동합니다.
- [영상 검사](video-checks-v01.json): 홈팀 약19.45초, 원정팀 약16.53초, 둘 다 1280×720이며 디코딩 오류가 없었습니다. 초반 입장 방향과 마지막 1루 베이스 대기를 화면으로 확인했습니다.
- [그림·문서·단일파일 검사](artifact-checks-v01.json): PNG 무결성과 문서 링크, 단일 HTML 재생성 일치, 원본 경기장 배경과 복사본의 동일 여부를 확인한 기록입니다.

## 소스와 다시 만들기

[소스 HTML](index.html), [동작/경로/합성](preview.js), [스타일](preview.css), [단일 파일 생성 도구](build-single.py)를 저장했습니다. `continuation-data.js`는 기존 1루 미리보기의 단일 HTML을 담은 로컬 재사용 자료입니다. 외부 네트워크나 게임 원본을 불러오지 않습니다. 이 폴더에서 새 이름으로 다시 만들 수 있습니다.

```text
python build-single.py 새미리보기-v04.html
```

기존 출력은 덮어쓰지 않습니다. 단일 HTML v01/v02와 그림 v01은 이력입니다. 현재는 HTML v03과 그림 v02를 먼저 봅니다. 게임 원본 구현/, 구단 저장과 배포는 변경하지 않은 독립 시안입니다.
