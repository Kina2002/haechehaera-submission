- 아직 실제 게임에 적용하지 않은 시안입니다.

## 여는 방법

`deployment-output/원근감-개선-시안-2026-11-05-v01.html`을 Chrome이나 Edge에서 두 번 클릭해 엽니다. 파일 크기는 약 100MB이고 인터넷 연결이 필요 없습니다.

이 파일이 없거나 게임 코드를 바꾼 뒤 다시 만들려면 저장소 최상위 폴더에서 아래 명령을 실행합니다.

```text
python 시안/원근감-개선-시안-2026-11-05-v01/build-single.py
```

## 화면에서 해 볼 것

1. 열면 입장 연출 뒤 자동 경기가 시작됩니다.
2. 오른쪽 아래 패널에서 **수비 장면 고정**을 누르면 만루 수비 장면에서 멈춥니다. 선수가 가장 많이 보이는 장면입니다.
3. **수정 전 / 수정 후**를 번갈아 눌러 비교합니다. 경기장만 다시 그려지므로 같은 장면을 그대로 비교할 수 있습니다.
4. 네 가지 항목을 하나씩 끄고 켜며 어떤 효과가 마음에 드는지 고릅니다. **강도** 막대로 원근의 세기(0~150%)를 조절할 수 있습니다.
5. **경기 재개**를 누르면 움직이는 장면에서도 확인할 수 있습니다.
