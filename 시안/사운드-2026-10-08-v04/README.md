각각 같은 이름의 WAV도 제공합니다. 짧은 버전은 현재 게임의 캐릭터 반응 표시 시간인 5초에 맞춘 별도 두 마디 편곡입니다. 긴 버전은 여덟 마디 뒤 잔향을 줄여 마무리합니다. 이번 파일은 반복 재생 전용으로 연결한 루프가 아닙니다.

관객 음악은 밝거나 익살스러운 멘트를 위한 후보입니다. 우울한 관객 장면에 이 음악을 자동으로 연결하는 결정은 하지 않았습니다.

## 제작 방식과 출처

- 멜로디·화성·베이스·드럼 패턴을 이번 게임용으로 직접 구성한 기악 시안입니다. 기존 응원가·방송 시그널의 멜로디나 완성곡을 가져오지 않았습니다.
- 단순 파형 대신 **GeneralUser GS 2.0.3**의 금관·오르간·피아노·기타·베이스·드럼 악기 음색으로 작성한 MIDI를 연주했습니다. 외부 음악 생성 서비스나 사람 목소리는 사용하지 않았습니다.
- 악기 음색: S. Christian Collins, [GeneralUser GS 공식 저장소](https://github.com/mrbumpy409/GeneralUser-GS). 배포자가 음악 제작을 허용하는 자체 라이선스를 제공합니다. 정확한 조건과 샘플 출처에 대한 배포자 설명은 [동봉 라이선스](sources/LICENSE-GeneralUser.txt)에 보존했습니다.
- 렌더러: [FluidSynth 2.6.1](https://github.com/FluidSynth/fluidsynth/releases/tag/v2.6.1). 악보 작성에는 mido, 파형 처리에는 numpy/scipy/soundfile, MP3 변환에는 lameenc를 사용했습니다.
- SoundFont SHA-256: `9575028c7a1f589f5770fccc8cff2734566af40cd26ed836944e9a5152688cfe`.
- 악기 원본과 실행 도구는 로컬 제작 도구 폴더에 보관합니다. 이 폴더에는 완성 WAV/MP3와 편집 가능한 MIDI, 제작 코드를 보관합니다.

## 확인 사항

- WAV·MP3 7쌍을 실제로 읽어 스테레오·44.1kHz·길이·무음·피크·시작과 끝을 확인했습니다. [음원 검사 결과](audio-checks.json).
- 4배 보간한 파형 피크를 제한했으며 모든 곡을 동일한 처리 방식으로 출력했습니다. LUFS 기준 방송 마스터링을 의미하지 않습니다.
- 곡의 취향·악기 균형·장면과의 어울림은 직접 들어보고 판단할 대상입니다. 모델이 귀로 청취한 결과로 표기하지 않았습니다.
- 재생 화면에는 자동 재생이 없으며, 한 번에 한 파일만 재생하고 모두 정지할 수 있습니다.
- 게임 소스·실행 파일·자산 목록·저장 데이터·공개 게임 사이트는 변경하지 않았습니다.

## 다시 만들기

`compose.py`는 존재하지 않는 새 `--out` 폴더에만 출력합니다. `--fluidsynth`에 실행 파일, `--soundfont`에 위 해시의 SF2, `--deps`에 필요한 Python 패키지 위치를 지정합니다. 모든 악보는 `midi/`에 있습니다. 최종 파일에는 작은 앞뒤 페이드와 완만한 진폭 압축을 적용합니다.
