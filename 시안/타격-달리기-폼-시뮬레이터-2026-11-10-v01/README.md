# 타격폼·달리기폼 제안과 동작 비교 시안

> **이전 비교본입니다.** 이 버전은 별도 코드 캐릭터를 써서 사용자 지정 외형과 달랐습니다. 현재는 [기준 캐릭터를 적용한 v02](../타격-달리기-폼-시뮬레이터-2026-11-10-v02/README.md)를 사용합니다. 아래 내용과 파일은 이전 제안의 이력으로 보존했습니다.

2026년 11월 10일, 수업 중 비교할 수 있도록 타격 6종과 달리기 6종의 공통 폼 후보를 제안한 시안입니다. 사용자가 시안 그림 또는 HTML 시뮬레이터를 요청하여 제작했습니다.

**최종 폼·그림체·성격별 조합을 확정한 자료가 아닙니다.** 같은 새 기준 선수로 자세와 리듬을 비교하는 동작 연구입니다. 새 얼굴·소품 파츠의 분리 제작과 게임 합성은 아직 하지 않았습니다.

## 이번 제안의 원칙

- **능력치·개인 폼·성격 표현을 분리합니다.** 내향적이거나 소심하다고 느리거나 서툰 동작에 고정하지 않습니다.
- 폼은 여러 성격이 공유하는 후보입니다. 성격마다 선호할 만한 대표 후보 3개씩을 제안했으며, 다른 폼을 선택해도 됩니다.
- 달리기 6종은 같은 기준 속도를 사용합니다. 긴 보폭은 발 교대가 적고, 짧은 보폭은 발 교대가 잦도록 조정해 자세와 실제 이동 속도를 구별합니다.
- 캐릭터는 같은 외형·배색으로 고정합니다. 성격 선택은 추천 표시만 바꾸며 선수 능력이나 속도를 바꾸지 않습니다.

## 타격폼 후보

| ID | 이름 | 주된 차이 |
| --- | --- | --- |
| B01 | 기본 균형 | 작은 준비, 일정한 중심, 짧은 마무리 |
| B02 | 다리 높이 들기 | 높은 앞무릎, 내딛기, 큰 마무리 |
| B03 | 낮게 모으기 | 낮은 머리·굽힌 무릎에서 위로 펴지는 동작 |
| B04 | 넓게 서기 | 넓은 발 간격, 큰 다리 들기 없이 몸통 회전 |
| B05 | 배트 높게 들기 | 세운 상체와 높은 손, 위로 긴 준비·마무리 |
| B06 | 배트 낮게 흔들기 | 낮은 배트와 준비 리듬, 짧게 끊는 마무리 |

분할동작은 준비 → 힘 모으기 → 딛기 → 맞히기 → 마무리 → 복귀입니다. 모두 같은 타격 시점을 기준으로 비교합니다.

## 성격별 대표 후보 제안

각 성격에 3개씩 제안한 첫 비교안입니다. 배타적인 배정이나 고정 규칙이 아닙니다.

| 성격 | 타격 후보 | 달리기 후보 |
| --- | --- | --- |
| 열혈 | B02 · B03 · B04 | R01 · R03 · R06 |
| 소심 | B01 · B03 · B05 | R01 · R02 · R05 |
| 허세 | B02 · B04 · B05 | R03 · R04 · R06 |
| 느긋 | B01 · B04 · B06 | R02 · R04 · R05 |
| 엉뚱 | B02 · B05 · B06 | R03 · R05 · R06 |
| 투덜이 | B01 · B03 · B06 | R01 · R02 · R05 |

소심한 선수도 앞으로 기울여 적극적으로 달릴 수 있고, 느긋한 선수도 짧은 보폭으로 빠르게 달릴 수 있습니다. 성격 차이는 향후 준비 버릇·시선·리듬·결과 반응을 함께 보며 더 정리합니다.

## 범위와 한계

- 현재 게임 캐릭터 그림을 불러오지 않고 기준 선수를 새로 그린 비교용 시안입니다. 앞서 검토한 최종 도트 스타일을 승인하거나 대체한 것은 아닙니다.
- 측면·비스듬한 방향에서 폼을 읽는 데 집중했습니다. v04의 낮은 공격/높은 주루 카메라에 실제로 합성한 검증은 아직 아닙니다.
- 좌·우타 선택은 방향 비교를 위한 반전입니다. 손잡이·비대칭 얼굴·장비를 포함한 제작용 방향별 자산 검증은 별도로 필요합니다.
- 스윙의 3차원 회전, 발목·손목, 타격 순간 접촉과 중간 자세 연결은 추가 보완이 필요합니다. 현재 그림을 최종 스프라이트 시트로 사용하지 않습니다.
- 본래 논의한 타격 후 출발·진루·슬라이딩·세리머니·삼진/아웃 반응을 전부 만든 것은 아닙니다. 이번에는 기본 타격·달리기 폼 선택에 한정합니다.
- 게임 원본·구단 저장·실제 경기 판정과 연결하지 않았습니다. 네트워크나 브라우저 저장 공간을 사용하지 않습니다.

## 파일과 재생성

`forms.js`는 12개 후보와 성격별 추천, `motion.js`는 기준 선수와 동작, `study.js`는 비교 화면과 PNG 저장 기능입니다. `index.html`과 `study.css`가 개발용 화면입니다.

단일 파일 재생성:

```text
python build-single.py 다른-출력파일.html
```

기존 결과를 덮어쓰지 않습니다. 분할 PNG는 시뮬레이터에서 종류를 선택하고 **6종 분할 PNG 저장**으로 다시 얻을 수 있습니다.
