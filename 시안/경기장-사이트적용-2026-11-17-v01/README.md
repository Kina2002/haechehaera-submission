# 새 캐릭터 · 공격/수비 경기장 사이트 적용 — 2026-11-17

기존 공개 v15 게임 로직을 기준으로 최신 11월17일 캐릭터 파츠와 경기장 구도를 연결했습니다. 반려된 v16 얼굴 파츠는 사용하지 않습니다.

## 화면과 규칙
- 선수창: 상세 얼굴 10종의 부위 조합, 헤어15종, 피부3색·홍채3색·헤어/눈썹6색, 액세서리와 모자ON/OFF. 최신 전신6체형에서 몸을 분리해 같은 외형에 연결했습니다.
- 경기장: 6체형×77자세와 방향별 얼굴/헤어/장비를 합성. 선수별 appearance.v17을 저장해 선수창과 경기장에서 같은 외형ID·색을 사용합니다.
- 타자·주자는 헬멧, 수비 투수·야수는 야구모자, 수비 포수는 마스크/헬멧·가슴/다리 보호대. 선수창 모자OFF는 경기 필수 장비에 영향을 주지 않습니다.
- 공격은 포수 뒤 낮은 시점. 1·3루가 모두 보입니다. 타구/주루 진행 및 수비는 넓은 시점입니다.
- 전광판: 이닝별 R/H/E 점수 + 현재 공격팀 9명 타순. 잔디 하단: 타자/투수 얼굴과 정보. 판단·시프트, 소리·선수교체·자동/반자동·배속·일시정지, 최근 상황/펼치는 경기기록을 유지합니다.
- 현수막은 기존 여론 규칙 연결. 심판과 판정 표현 유지.
- 타자 등장: 홈팀 오른쪽/원정팀 왼쪽. 베이스 도착 후 발(헤드퍼스트 회복 중에는 손) 접촉 유지. 태그아웃은 베이스 대기로 강제하지 않습니다.

## 이번 검수에서 수정
- 모자 토글이 선수 목록 버튼 안에 들어가던 HTML을 선수 상세창으로 이동.
- 좌타 준비 동작도 좌우 적용. 머리만 강제로 뒤로 돌리던 타격 처리 제거; 자세 등록 방향 유지.
- 대기 포수는 공격/수비 카메라 모두 뒤 방향, 뒤 보호대 끈 적용. 공격 타석의 포수 출신 선수는 포수장비를 착용하지 않음.
- 홈 심판이 타자와 겹치던 위치 조정.
- 최근 상황 패널 높이를 제한해 홈 주변 선수 가림 감소.
- 선수창 전신6체형의 목 접점·피부/유니폼 색 연결. 인접 칸에서 남은 얇은 잔점은 가장 큰 몸 연결 영역만 보존하여 제거.

## 빌드와 범위
- 웹: 저장소 루트에서 `python tools/build-web.py`. dist/를 기존 Sites 프로젝트에 배포합니다.
- 오프라인 단일HTML: 구현 폴더의 build.py로 재생성 가능(119,391,515바이트, 재현성 확인). 대형 단일HTML은 GitHub 단일파일 한도를 넘으므로 이번 커밋에는 갱신하지 않았으며, 기존 오프라인 파일은 보존했습니다. 이번 적용 대상은 웹사이트입니다.
- tools의 export/add-portrait 스크립트는 원본 시안 경로가 있는 제작 환경용입니다. 일반 웹 빌드는 커밋된 assets/src만 사용합니다.
- 사용자 미술 최종 승인과 자체 검수를 구분합니다. 모든 얼굴×헤어×액세서리×자세 조합을 수동 검수한 것은 아닙니다. 모바일 세로 최적화는 이번 범위 밖이며 경기 화면 최소폭680px을 유지합니다.
