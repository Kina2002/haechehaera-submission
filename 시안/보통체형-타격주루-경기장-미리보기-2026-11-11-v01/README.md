# 보통 체형 · 타격에서 1루까지 · 경기장 미리보기

**상태: 새 보통 체형의 동작 연결을 최신 경기장에 합성한 독립 시안 · 실제 게임 미적용.**

사용자는 공통 연결/방향 전환, 본헤드 실수/수습, 입퇴장 동작도 목록에 포함하고, 먼저 새 보통 체형으로 서기부터 타격·1루 진루·감속까지 적용해 보여 달라고 요청했습니다(2026-11-11). [추가 동작 채택과 제작 범위](../타자-주자-동작-디자인-2026-11-11-v02.md)를 별도로 기록했습니다.

## 새 뼈대와 경기장

[6체형 원본](../캐릭터-리디자인-시안-2026-11-09-v01/이미지도구/경기장용-체형별-뼈대-6종-v01.png)의 **왼쪽 첫 번째 보통형**을 참조했습니다. 다른 체형이나 예전의 머리카락/얼굴 포함 선수를 대신 쓰지 않았습니다. 빈 머리·귀, 초록 상의/양말, 흰 바지/소매 끝, 어두운 신발을 유지한 동작 변형입니다.

머리카락·모자·눈코입·등번호는 비워 두었습니다. 피부색은 임시 견본색이며 색 교체용 마스크와 얼굴/머리 파츠 결합 기능은 이번 범위에 없습니다. 원본을 참고한 생성 변형이므로 픽셀 단위 복제나 정밀40px 제작 자산으로 보지 않습니다.

[현수막 채택 공수 그림](../해체-여론-현수막-공수-시안-2026-11-11-v01/README.md)을 바탕으로 배경2장을 생성 편집했습니다. 낮은 화면의 기존 타자를 비우고 포수를 쪼그리게 했으며, 높은 화면에서는 기존 타자/주자와 수비 지시 칸을 비웠습니다. 높은 화면의 점수·공격 타순·인물 정보도 낮은 화면과 같은 우리 공격 상황으로 맞췄습니다. 점수판·공격 라인업·평온 현수막·전체 조작·얼굴 정보·작은 기록·4심이 보이는 구성을 유지했습니다.

이번 배경의 다른 선수/심판은 정지 그림이며 두 팀 몸 색도 임시 공통 초록입니다. 움직이는 대상은 보통형 타자→주자1명과 배트/공입니다. 배경에 그려진 버튼은 동작하지 않고, 미리보기 아래 재생 도구만 작동합니다. 배경 경기 내용은 고정 예시입니다.

## 이미지 원본과 최종 요청문

내장 GPT 이미지 도구의 참조 편집을 사용했습니다. 생성 PNG는 원본 그대로 복사했고, 프레임을 Canvas에서 골라 합성·재생합니다. Python으로 그림을 보정하지 않았습니다.

- [24칸 동작 v02](보통형-동작24칸-v02.png): 선택본, 1536×1024 RGBA, 6열×4행.
- [동작 최초 요청](atlas-생성요청문-v01.txt) · [방향/투명 가장자리 정리 요청](atlas-방향투명정리-생성요청문-v02.txt). [동작 v01](보통형-동작24칸-v01.png)은 초기 이력.
- [낮은 공격 배경](경기장-낮은공격-배경-v01.png) · [요청문](low-생성요청문-v01.txt).
- [높은 주루 배경](경기장-높은주루-배경-v01.png) · [요청문](high-생성요청문-v01.txt).

동작 칸은 서기/배트 들기/준비/힘 모으기/접촉/마무리, 배트 내리기/놓기/출발2칸/달리기2칸, 달리기4칸/베이스 접촉/통과, 감속3칸/걷기/멈춤/돌아보기 순서입니다. 10–15번의6칸을 달리기에 반복 사용합니다(번호0부터).

프레임 간 손·배트·몸 회전, 카메라에 따른 원근과 정확한 발 접촉은 후속 제작에서 더 다듬어야 합니다. 접촉 칸의 배트가 옆 칸으로 조금 넘어간 부분은 Canvas의 자르기 영역으로 처리했습니다. 원본 PNG를 수정하지 않았습니다. [frames.json](frames.json)은 읽기 전용 이미지 분석 결과이며 실행 중에는 사용하지 않습니다.

## 확인한 범위

Ego Browser에서 단일 HTML이 준비되고 그림이 보이는지,8단계 선택과 전체 재생 종료, 일시정지,1.5배, 카메라 고정/자동, PNG 저장, MP4 저장과 실제 재생을 확인했습니다. 8.2초의 주자 기준점이 높은 화면1루 위치(1239,581)에 도착하는 상태도 확인했습니다. 이것은 시안 좌표 기준이며 게임 엔진/야구 판정의 검증이 아닙니다.

1536×706 브라우저에서 세로 스크롤 없이 화면/조작/단계가 함께 보이도록 맞췄습니다. 사용자 직접 확인과 최종 채택은 아직 별개입니다. 원본 구현/, 기존 시안·이미지·실제 구단 저장·배포는 변경하지 않았습니다.
