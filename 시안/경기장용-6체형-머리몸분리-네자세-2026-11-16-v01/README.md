## 이번 결과

보통형에서 분리한 **머리 PNG와 보통 몸 PNG는 바이트 그대로 복사**했습니다. 머리를 새로 그리지 않았습니다. 나머지 다섯 체형은 머리 없는 몸 그림을 새로 제작하고 서기·달리기·타격·고개 숙임을 비교했습니다. 사용자 최종 채택 전 시안이며, 보통형을 기준으로 삼았다는 뜻이지 전체 동작·파츠가 승인되었다는 뜻은 아닙니다.

- 중량형: 가슴·몸통·팔·허벅지를 두껍게. 배가 튀어나온 둥근 실루엣은 피함.
- 어깨 넓은형: 어깨에서 허리로 좁아지는 윤곽. 중량형보다 가는 허리와 다리.
- 날렵형: 좁은 몸통과 가는 팔다리. 키 큰형보다 짧게.
- 키 큰형: 긴 몸통과 팔다리, 여섯 체형 중 가장 큰 키.
- 작은형: 몸통과 팔다리를 짧게. 유아 비례로 새로 바꾸지 않음.

중량형·어깨형은 첫 결과의 너비 차이가 약해 v02에서 한 번 더 수정했습니다. 체형과 성격·능력치·개인 폼은 별개로 둡니다.

## 붙이는 방식과 키 기준

큰 원본 그림의 빈 여백과 생성 위치는 체형마다 달라서, 다른 체형의 몸 PNG에 공통 머리 PNG 전체를 단순히 (0,0)에 겹치지 않습니다. **머리는 공통 파일, 몸은 체형별 파일, 붙일 자리는 자세별 목 위치**입니다. [머리몸-배치기준-v01.json](머리몸-배치기준-v01.json)에 각 그림의 잘라 읽을 영역·목 위치·지면·머리의 상대 위치를 기록했습니다. 미리보기는 이 자료로 실제 두 이미지를 따로 그립니다.

키 차이는 [기존 6체형 정면](기존-6체형-정면기준.png)의 불투명 윤곽 높이 551/570/584/581/623/509 비율을 참고했습니다. 보통형을 40픽셀로 놓고 나머지는 같은 상대 비율로 비교합니다. 이전 새 머리 실험의 40/42/43/42/46/36 값이나 18×16 머리는 재사용하지 않습니다. 표의 소수 키는 비교용 환산값이며 최종 게임 정수 격자 규격은 아닙니다.

생성된 몸의 캔버스 내 크기 차이는 **체형당 하나의 균일 축척**으로 보정했습니다. 가로와 세로에 같은 배율을 쓰고, 네 자세에도 같은 배율을 씁니다. 머리에는 체형별 확대·축소를 하지 않습니다. 각 자세의 발바닥을 같은 지면에 놓되, 굽힌 자세의 전체 키를 서기와 같게 늘리지 않습니다.

## 확인 범위

- [원본 동일성 확인](원본-동일성-확인.json): 공통 머리·보통 몸이 이전 분리 PNG와 동일하고, 새 몸은 선택한 GPT 출력과 동일함을 파일 해시로 확인.
- [브라우저 확인](브라우저-확인-v01.json): 6체형 × 4자세의 64×64 표시칸, 보통 서기 40픽셀 기준. 모든 칸에서 가장자리 잘림 없음, 발바닥 마지막 불투명 행 y56 일치.
- 분리한 머리와 몸의 불투명 픽셀은 24칸 모두 겹치거나 바로 인접함. 이 최소 거리 검사는 큰 빈틈 발견용이며 목 윤곽 전체가 완성되었다는 뜻은 아님.
- 머리만·몸만·합쳐 보기, 자세 전환, 밝은/어두운 바탕 표시 확인. 가로 화면 넘침 없음.
- [밝은 바탕 타격 비교](6체형-타격-밝은바탕-확인.png)와 확대 네 자세를 육안 검토.

아직 정지 시안입니다. 머리의 좌우·옆·뒤 방향을 모두 완성한 것이 아니며, 연속 프레임·팔/장비의 앞뒤 가림·실제 경기장 동작은 후속입니다. 생성 PNG의 미세한 반투명 경계, 색·픽셀 격자 정리도 최종 자산 단계에서 확인합니다. 피부색과 눈동자색은 바뀌어야 한다는 기존 계획을 유지하되 이번에는 색 교체 영역/눈 파츠를 만들지 않았습니다.
