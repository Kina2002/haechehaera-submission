## 타격음도 경쾌하게

- [일반 타격 · 짧게 딱!](audio/06-bat-crisp.mp3): 0.25초 파일. 나무의 중고음 충격을 강조하고 긴 잡음과 낮은 울림을 줄인 합성 시안입니다.
- [홈런 타격 · 더 선명하게 딱!](audio/07-homerun-bat-crisp.mp3): 0.29초 파일. 일반 타격과 구분되도록 조금 더 높은 나무 울림을 사용했습니다.
- [전후 비교 3.74초](audio/00-bat-before-after.mp3): **일반 이전 → 새 일반 → 홈런 이전 → 새 홈런**. 비교 파일 전체에 같은 음량 감소를 적용해 이전 음원의 순간 피크를 제한했습니다. 비교 안에서 각 소리의 상대 음량은 유지했습니다.
- 홈런 타격음은 배트 접촉 순간용이고, 사용자가 선택한 4초 관중 환호는 홈런 직후 축하용입니다.

## 파일과 제작

- WAV·MP3 10쌍: 상황 소리 5개, 새 타격음 2개, 비교 모음 3개. 모두 스테레오 44.1kHz, MP3 192kbps입니다.
- `00-new-three`는 마이크 → 우리 관객 우울 → 상대 치어리더 조롱 순서로 11.72초입니다. `00-all-roles`는 표의 다섯 상황 순서로 23.02초입니다.
- 마이크와 타격은 직접 합성한 소리입니다. 마이크 시안은 실제 장비의 녹음이 아니며, 말소리·멜로디·긴 잡음은 넣지 않았습니다.
- 새 BGM은 이번에 직접 작성한 악보를 **GeneralUser GS 2.0.3** 악기 음색과 FluidSynth 2.6.1로 연주했습니다. [악기 제작자 공식 저장소](https://github.com/mrbumpy409/GeneralUser-GS) · [라이선스 원문](sources/LICENSE-GeneralUser.txt).
- 새 BGM의 MIDI는 `midi/`, 제작 코드는 `make_v05.py`입니다. v04에서 이어 쓰는 음악은 WAV·MP3를 바이트 그대로 복사했습니다.
- 필요한 도구는 v04에서 사용한 mido/numpy/scipy/soundfile/lameenc와 외부 FluidSynth 실행 파일입니다. `make_v05.py --out`은 존재하지 않는 새 폴더를 받으며, `--previous`에는 v04 폴더를 지정합니다.
