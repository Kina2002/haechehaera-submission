# 기준 캐릭터의 타격폼·달리기폼 비교 v02

사용자가 다시 지정한 **어제의 경기장용 캐릭터**를 기준으로 고친 버전입니다. 이전 v01은 별도 코드 캐릭터를 그려 외형이 달랐으므로 이번 검토에는 사용하지 않습니다. 큰 머리, 갈색 머리, 길쭉한 도트 눈, 초록 모자·상의와 짧은 팔다리를 참고해 분할동작을 생성했습니다.

- 실행: **[폼 비교 시뮬레이터 v02](폼-비교-시뮬레이터-v02.html)** — 내려받아 Chrome/Edge에서 열면 네트워크 없이 실행됩니다.
- [12종 한눈에 보기](폼-후보-한눈에-v02.png)
- [타격 6종 × 6칸](타격폼-6종-분할동작-v02.png)

## 폼 제안

| 번호 | 타격폼 | 달리기폼 |
| --- | --- | --- |
| 01 | 기본 균형: 작은 준비와 안정된 중심 | 앞으로 기울이기: 전경 자세와 몸 가까운 팔치기 |
| 02 | 다리 높이 들기: 큰 무릎 들기와 내딛기 | 상체 세우기: 곧은 몸통과 적당한 보폭 |
| 03 | 낮게 모으기: 무릎을 굽혀 모았다 펴기 | 무릎 높이 들기: 다리를 높이 접는 탄력 |
| 04 | 넓게 서기: 발을 넓게 두고 회전하기 | 큰 보폭: 앞뒤로 길게 벌어지는 발 |
| 05 | 배트 높게 들기: 높은 손 위치와 세운 상체 | 짧은 보폭: 작은 걸음을 자주 바꾸기 |
| 06 | 배트 낮게 흔들기: 낮은 배트로 리듬 잡기 | 팔 크게 치기: 팔꿈치의 앞뒤 움직임 강조 |

타격은 준비 → 힘 모으기 → 딛기 → 맞히기 → 마무리 → 복귀의 6칸입니다. 달리기는 양발의 지지·밀어내기·교대를 비교하는 6칸입니다. 성격을 고르면 아래 세 후보를 표시하되 모든 폼을 계속 선택할 수 있습니다.

| 성격 | 타격 후보 | 달리기 후보 |
| --- | --- | --- |
| 열혈 | B02·B03·B04 | R01·R03·R06 |
| 소심 | B01·B03·B05 | R01·R02·R05 |
| 허세 | B02·B04·B05 | R03·R04·R06 |
| 느긋 | B01·B04·B06 | R02·R04·R05 |
| 엉뚱 | B02·B05·B06 | R03·R05·R06 |
| 투덜이 | B01·B03·B06 | R01·R02·R05 |

폼은 여러 성격이 공유합니다. 소심함이 느린 달리기를 뜻하거나 큰 동작이 높은 능력치를 뜻하지 않습니다. 달리기는 지면의 이동 속도를 동일하게 두고, 그림과 발 교대 빈도를 달리해 비교합니다. 실제 주자의 속도·거리·발 접촉을 계산하는 게임 물리 시뮬레이션은 아닙니다.

## 조작과 확인 범위

카드를 선택하면 큰 보기와 6칸이 바뀝니다. 재생·일시정지·배속·칸별 선택·작은 크기·실루엣·분할 PNG 저장을 지원합니다. 좌타는 우타 그림의 좌우 반전 비교입니다. 현재 카메라는 동작이 잘 보이는 오른쪽 사선 방향이며, 낮은 공격 시점이나 높은 주루 시점에 합성한 결과는 아닙니다.

이것은 **생성한 6장의 그림을 순서대로 넘기는 폼 검토본**입니다. 원본 캐릭터를 참고한 동작 변형이므로 픽셀 하나까지 동일한 원본 복제는 아닙니다. 프레임 사이 머리·모자·손·배트의 모양과 위치, 타격의 회전, 좌우타 손잡이, 지지발 연결은 최종 제작 전에 다듬어야 합니다. 약 40px 크기 보기는 축소 인상을 확인하기 위한 것이며, 40px 원본 격자·색상 수·얼굴/장비 파츠 결합까지 검증한 완성 스프라이트는 아닙니다.

## 이미지 원본과 생성 요청문

OpenAI 내장 `imagegen`의 참조 이미지 편집 모드, 투명 배경으로 생성했습니다. 코드로 새 선수를 그리는 방식을 제거하고 아래 PNG의 칸을 Canvas에 표시합니다. 생성 원본 PNG는 변경하지 않았습니다.

- 기준: [전신](기준-캐릭터.png), [기존 대기동작](기준-캐릭터-동작참고.png). 전날 캐릭터 폴더의 원본을 복사했습니다.
- B01–B03: [투명 PNG](타격-기준캐릭터-B01-B03-v01.png), [요청문](요청문-bat-a-v01.txt)
- B04–B06: [투명 PNG](타격-기준캐릭터-B04-B06-v01.png), [요청문](요청문-bat-b-v01.txt)
- R01–R03: [투명 PNG](달리기-기준캐릭터-R01-R03-v01.png), [요청문](요청문-run-a-v01.txt)
- R04–R06: [투명 PNG](달리기-기준캐릭터-R04-R06-v01.png), [요청문](요청문-run-b-v01.txt)

각 PNG는 1774×887, 3행×6열이며 알파 채널이 있습니다. 그림에는 글자·로고가 없고, 비교표의 이름은 HTML/Canvas에서 그림 밖에 붙였습니다. 기존 게임·만화 캐릭터를 추가 참조하지 않았습니다. 게임 원본 `구현/`은 이 작업에서 수정하지 않았습니다.

소스를 수정하고 단일 HTML을 다시 만들 때는 `python build-single.py 새출력경로.html`을 실행합니다. 빌드는 그림을 포함하므로 결과 HTML 하나로 실행할 수 있고, 이미 있는 출력 파일은 덮어쓰지 않습니다.
