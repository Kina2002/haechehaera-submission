# 경기 반응 중앙 통과

사용자가 승인한 v03 시뮬레이션을 공격·수비 경기 화면에 적용합니다.

- 중계진·우리/상대 관객·우리/상대 치어리더가 경기장 중앙 높이(55%)를 왼쪽에서 오른쪽으로 통과합니다. 중앙에서도 멈추지 않고 천천히 이동합니다.
- 작은 화면에서도 경기장 안에 표시하며 아래에 별도 반응 줄을 만들지 않습니다.
- 1배속 기준 중계진 4.95초, 관객 4.46초, 치어리더 4.6초입니다. 자동 경기 배속은 기존 규칙대로 적용합니다.
- 말풍선 배경 불투명도 65%, 테두리 60%. 글자와 인물은 불투명하게 유지합니다.
- 기존 사건별 화자·대사·우리/상대 팀색과 실망한 관객 그림을 그대로 사용합니다.
- 플레이 결과가 나온 뒤 등장하며, 기존 반응 시간과 같은 시계로 움직입니다. 일시정지·이어 재생·배속 변경·화면 크기 변경 시 처음부터 다시 시작하지 않습니다.
- 반응이 보이는 동안 판단 버튼만 숨기고, 끝나면 복귀합니다. 점수판·공격 라인업·타자/투수 얼굴과 정보·경기 기록은 유지합니다.
- 반응은 경기장 최상단 표시 영역에 배치합니다. 사용자가 연 전체 경기 기록 창은 반응보다 위에 표시됩니다.
- 모션 줄이기 설정에서는 중앙에서 나타났다 사라지는 방식으로 같은 시간을 유지합니다.

## 구현과 확인

구현 파일은 게임의 `src/stadium-reactions-v26.js`, `src/stadium-reactions-v26.css`이며 `dev.html`에서 불러옵니다. 경기 판정·능력치·선수 외형·저장 자료는 수정하지 않습니다. 공개 v25의 타격·수비 개선을 보존하고 새 파일 두 개와 진입 HTML만 배포합니다.

새 단위검사 7개와 기존 반응/자동배속 검사 12개가 통과했습니다. 브라우저에서 공격/수비 × 668/852/1179픽셀, 다섯 화자별 긴 대사 5개, 중앙 위치·글자 잘림·반투명도·재렌더 진행 유지·판단 버튼 복귀를 확인했습니다. 실제 경기 시계에서 플레이 결과 전 숨김, 이후 등장, 일시정지 시 위치/시간 유지와 종료 복귀를 확인했습니다.

재현 도구와 검사 결과는 게임의 `tests/stadium-reactions-v26-qa.js`, `tests/stadium-reactions-layout-20261117.json`에 있습니다. 실제 화면 캡처는 `tests/reaction-central-attack-20261117.png`, `tests/reaction-central-defense-20261117.png`입니다.
