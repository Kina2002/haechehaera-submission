# 포수 정리와 방향별 수비 연결 — 2026-11-17

포수를 알아보기 어려웠던 원인은 뒤를 보는 머리와 다른 방향의 몸에 보호장비를 겹쳐 붙인 조합이었습니다. 전용 쪼그림 몸을 만들고 머리·마스크·등 보호대·무릎 보호대를 같은 방향으로 연결했습니다. 주심은 포수 뒤에서 타자 반대쪽으로 조금 비켜 섭니다.

## 제작한 그림

- 정면 F / 오른쪽 반측면 FR / 오른쪽 R / 뒤 오른쪽 BR / 뒤 B / 뒤 왼쪽 BL / 왼쪽 L / 왼쪽 반측면 FL.
- 방향마다 이동 2칸, 땅볼 포구·받기·공 확보 3칸, 송구 준비·놓기·마무리 3칸, 포수 쪼그림·투구 받기 2칸.
- GPT 이미지로 보통형 원본 80자세를 제작하고 기존 6체형의 폭·목 높이에 맞춰 **480개 등록 자세**로 변환했습니다. 480개를 각각 별도로 그렸다는 뜻은 아닙니다.
- 완성 캐릭터를 좌우 반전하지 않습니다. 이번 세트는 기존 준비 그림과 같은 **오른손 송구 / 왼손 글러브**입니다. 좌타·우타와 송구 손은 별개입니다.
- 송구 FL에서 바뀐 손과 이동 두 번째 발걸음을 이미지 도구로 보정했습니다. 송구는 보정본 마지막 열만, 이동은 보정본 아래 행만 사용합니다. 원본과 요청문을 모두 보존합니다.

## 기존 파츠와 맞추는 규칙

- 몸 64×64, 발 y56. 머리 33×36과 목 기준 (16,24)은 기존 그대로입니다.
- 서 있는 동작의 체형별 목 높이는 보통/중량35, 작은39, 키큰32, 어깨넓은/날렵34입니다. 쪼그림은 목부터 발까지 높이를 해당 체형의 80%로 낮춥니다.
- 뒤머리 → 몸 → 목걸이 → 얼굴/얼굴 장신구 → 앞머리 → 모자 → 장비 위 머리 → 앞팔 → 글러브 순서입니다. 포수의 목걸이는 보호대 안쪽으로 숨기고 안경은 마스크 안에서 중복되지 않게 숨깁니다. 선수의 저장된 외형 값은 바꾸지 않습니다.
- 피부1~5는 머리와 같은 팔레트, 주색50~53은 상의/양말, 부색60~62는 옷깃/소매 끝입니다. 바지70~73, 신발80~82, 글러브90~93, 보호대100~103은 팀색과 분리합니다. 모자 주색/부색은 기존 규칙을 사용합니다.
- 앞팔은 몸에서 해당 피부 픽셀을 위로 다시 얹는 가림 레이어입니다. 글러브 없는 맨손 몸을 복원한 세트가 아니므로 포구 자세에서 글러브를 함께 사용합니다.
- 뒤에서 본 포수의 가슴 앞 미트와 공은 몸에 가립니다. 공을 헬멧이나 등 위에 그리지 않습니다.

## 경기 연결

현재 이동 방향 / 들어오는 공의 출발점 / 송구 받을 선수의 도착 위치로 몸과 머리를 함께 고릅니다. 준비 상태에서는 홈을 봅니다.

준비 → 이동 2칸 → 포구 → 공 확보 → 송구 준비 → 놓기 → 마무리 → 준비 복귀입니다. 포수는 투구 받기 → 일어서서 송구 → 쪼그림 복귀로 연결합니다. 송구 뒤 과거의 잘못된 포수 그림으로 돌아가던 경로도 제거했습니다.

공은 새 그림의 글러브·맨손 좌표에 연결합니다. 중계 송구 사이에 잡고 바꿔 쥐는 시간을 둡니다. 최종 도착 및 세이프/아웃의 선후 관계를 검사하며 득점·아웃 판정 규칙은 바꾸지 않습니다. 베이스 커버는 보이는 발을 베이스에 붙입니다.

주심은 홈 포수 뒤에 배치합니다. 11월 18일 수정부터 좌타/우타와 관계없이 화면 오른쪽으로 조금 비키며, 대기 때만 작아지던 처리를 없앴습니다. 대기와 모든 판정에서 투수 쪽을 바라보도록 그림별 반전도 통일했습니다([현재 표시 기준](../주심-표시규칙-2026-11-18-v02.md)). 포수가 공을 쫓아 홈을 떠나도 주심이 함께 따라가지 않습니다.
