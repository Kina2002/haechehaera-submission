# 캐릭터 재검토 — 버전16 반려 후 수정 후보

> **후속:** 사용자가 기존 파츠 전면 재제작을 요청했습니다. 현재 얼굴 후보는 [새 눈코입 제작](../눈코입-전면재제작-2026-11-16-v01/README.md)입니다. 이 폴더의 위치 조정 후보는 이전 검토 이력으로 보존합니다.

공개 게임은 사용자 요청에 따라 **버전15로 복구**했습니다. 이 폴더는 로컬 수정 후보입니다. 디자인 완성·사용자 채택·사이트 재적용은 아직 아닙니다. PR #81은 초안입니다. 이전 수치 검사 통과를 미술 품질 완료로 판단한 것이 잘못이었습니다.

## 확인한 범위

버전16이 불러오는 원본 **48개**를 [목록](원본-검토목록-v01.json)과 원본 분해검토01~12 PNG로 펼쳐 확인했습니다. 6체형77자세 합성표도 확인했습니다. 현재 사용 자산의 개괄 검토이며 저장소의 모든 역사 이미지·모든 파츠 조합·모든 연속 장면 검수가 끝났다는 뜻은 아닙니다.

## 머리 방향 계약

[방향표](머리방향-원본연결-검토-v01.png) · [몸/머리 오류 비교](몸머리-방향오류-전후-v01.png)

| 방향 | 시험 코드 | 표시 규칙 | 상태 |
|---|---:|---|---|
| 정면 | 0 | 양쪽 눈, 얼굴 파츠 | 원본 있음·합성 재검토 |
| 앞 사선 | 1 | 가까운/먼 눈의 크기·가림 구별 | 원본 있음·합성 재검토 |
| 옆 | 4 | 옆얼굴 원본, 보이는 눈1개, 코는 윤곽 쪽 | 머리 연결 후보; 나머지 파츠 부족 |
| 뒤 사선 | 2 | 눈·코·입 없음, 귀·장비 방향 일치 | 원본 있음·몸과 짝 확인 필요 |
| 뒤 | 3 | 얼굴 파츠 없음 | 원본 있음·뒤 몸 동작 부족 |
| 앞으로 숙임 | 미정 | 정수리·챙·얼굴 가림 함께 변화 | 미완성, 화면 회전으로 대체 금지 |

코드 번호는 기존0~3 의미를 유지한 시험 값입니다. 번호가2 이상이면 뒤라고 추론하는 조건은 새 옆 방향4에 사용할 수 없습니다. 실제 게임의 포수/장비 코드도 재검토 대상이며 후보는 게임에 연결하지 않았습니다.

장면마다 **몸 방향 + 머리 방향 + 시선 + 장비 방향**을 함께 기록합니다. 카메라가 바뀌었다고 머리만 반대로 바꾸지 않습니다. 타구를 눈으로 보는 것과 몸 전체 방향 변경은 다릅니다. 좌우 반전 때 아이패치·헬멧 귀 보호대·가르마의 좌우도 별도 검토합니다.
