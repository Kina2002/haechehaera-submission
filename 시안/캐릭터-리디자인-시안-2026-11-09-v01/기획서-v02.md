# 해체해라 캐릭터 리디자인 기획 · 2026-11-09 v02

v01(`기획서.md`)에서 바뀐 점:
- 강점이 체형과 소품을 **정하지 않고 기울이기만** 하도록 고쳤습니다. 같은 강점끼리 똑같아 보이는 문제를 막기 위해서입니다.
- 비교 화면에 **같은 강점 선수 4명 줄**을 추가했습니다.
- 이미지 도구 시안은 선택 사항으로 바꿨습니다.

## 왜 다시 짜나요
- 지금 선수 외형(체형·피부·머리·수염·눈코입)은 **능력치와 상관없이 무작위**로 정해집니다. 겉모습만 봐서는 어떤 선수인지 알 수 없습니다.
- 실제 사람에 가까운 비율이라, 경기장에서 키 34~82픽셀로 줄이면 얼굴이 몇 픽셀만 남습니다. 표정과 개성이 보이지 않습니다.
- 그 결과 선수가 눈에 들어오지 않고, 애착이 생기지 않습니다.

## 원하는 결과
선수 하나하나가 눈에 들어오고, 겉모습만 봐도 **어떤 선수인지 짐작**이 가서 애착이 생기는 캐릭터입니다. 같은 강점을 가진 선수끼리도 **서로 다른 사람**으로 보여야 합니다.

**직접 확인할 방법**
1. 선수 3명(파워·주력·선구안)을 새 그림으로 보고 이름표 없이 강점을 짐작할 수 있는지 확인합니다.
2. 같은 강점(파워) 선수 4명을 나란히 놓고 서로 구별되는지 확인합니다.
3. 경기장 크기와 선수 카드 크기 모두에서 확인합니다.

## 그림 규칙
- **머리는 키의 약 40~45%** 크기로 그립니다. 가장 작은 외야수(키 약 34픽셀)도 머리가 약 14픽셀이 되어 눈과 입이 보입니다.
- **눈은 크고 단순하게**, 눈썹은 굵게 그립니다. 표정은 눈썹과 입 모양으로 나타냅니다.
- **진한 외곽선**을 두르고, **몸은 단순한 덩어리**로, 팔다리는 짧고 굵게 그립니다.
- **유니폼은 두 색 칸**으로 나눕니다. 주 색은 상의·바지, 부 색은 모자·소매·양말이고, 팀 색으로 바꿔 칠할 수 있어야 합니다.
- 기본 방향은 **오른쪽**입니다. 게임이 필요할 때 좌우로 뒤집어 씁니다.

## 겉모습을 정하는 방법: 강점은 "기울이기"만
선수 한 명의 겉모습은 아래 여섯 겹을 차례로 정해 만듭니다. 강점이 영향을 주는 것은 체형과 대표 소품뿐이고, 그마저 확률로만 정합니다.

| 겹 | 정하는 방법 |
|---|---|
| ① 체형(6종) | 강점에 맞는 체형이 뽑힐 확률 **50%**, 나머지 50%는 다른 체형 중 무작위 |
| ② 대표 소품 | 강점이 **뚜렷할 때만** 받습니다(가장 높은 능력치가 60 이상이고 두 번째보다 5 이상 높을 때). 강점마다 소품 3종 중 무작위 1개, 색도 무작위 |
| ③ 보조 소품 | 두 번째로 높은 능력치도 60 이상이면 그 강점의 소품 하나를 작게 더합니다(최대 2개) |
| ④ 개인 특징 | 모든 선수가 무작위 1개: 주근깨, 반창고, 발그레한 볼, 삐친 머리, 앞니 빠짐, 눈 밑 점, 덧니, 큰 귀 |
| ⑤ 얼굴·머리 | 지금처럼 무작위: 피부색 6종, 머리색, 머리 모양, 수염, 눈·코·눈썹·입 |
| ⑥ 성격(넣는 경우) | 4종 중 하나. 표정과 행동을 바꿉니다(아래 제안 참고) |

숫자(50%, 60, 5)는 시안을 보고 조정합니다.

### 강점별 어울리는 체형과 소품 후보
| 강점 | 뽑힐 확률이 높은 체형 | 대표 소품 후보(3종 중 1개) |
|---|---|---|
| 파워 | 크고 둥근 덩치 | 두꺼운 손목 밴드 / 팔뚝 테이핑 / 굵은 목걸이 |
| 주력 | 마르고 다리가 긴 날렵형 | 머리띠 / 형광 스파이크 / 바람에 날리는 머리 |
| 송구 | 어깨가 넓은 역삼각형 | 팔꿈치 보호대 / 어깨 테이핑 / 팔토시 |
| 구속 | 키가 크고 길쭉함 | 무릎까지 오는 긴 양말 / 목에 두른 수건 / 꺾은 모자챙 |
| 제구 | 작고 단정함 | 로진백 / 반듯하게 눌러쓴 모자 / 귀에 꽂은 펜 |
| 컨택 | 보통 | 밝은 배팅 장갑 / 손목 테이프 / 짧게 깎은 머리 |
| 선구안 | 보통 | 동그란 안경 / 네모 안경 / 눈 밑 검은 칠(아이블랙) |
| 야구센스 | 보통 | 모자 위 선글라스 / 풍선껌 / 거꾸로 쓴 모자 |
| 포구 | 보통 | 과장되게 큰 글러브 / 무릎 보호대 / 글러브 끈 장식 |

### 이렇게 하면 무엇이 달라지나요
- 처음 받는 선수 12명은 강점이 9가지 중 무작위라, 같은 강점인 선수가 적어도 3쌍은 생깁니다. v01 규칙이면 그 선수들은 체형과 소품이 똑같아집니다.
- v02 규칙이면 체형이 절반 확률로 달라집니다. 소품도 3종 중에서 고르고, 개인 특징과 얼굴이 따로 정해집니다. 그래서 같은 강점이라도 "덩치 큰데 안경 쓴 파워 타자", "마른데 목걸이 찬 파워 타자"처럼 서로 다른 사람이 됩니다.
- 새로 들어오는 선수는 능력치가 10~70에서 고르게 정해져 강점이 뚜렷하지 않은 경우가 많습니다. 그런 선수는 대표 소품 없이 개인 특징과 얼굴로 구별됩니다. 그래서 소품을 단 선수가 더 눈에 띕니다.

## 제안: 연출 전용 성격 (아직 결정 전)
- 능력치와 경기 결과에는 **영향이 없습니다.** 게임 규칙과 균형은 그대로입니다.
- 선수마다 4가지 중 하나를 정하고 바꾸지 않습니다.

| 성격 | 얼굴 | 행동·말풍선 예 |
|---|---|---|
| 열혈 | 치켜올린 눈썹, 크게 벌린 입 | 크게 기뻐하고 크게 아쉬워함 |
| 소심 | 처진 눈썹, 땀방울 | 작은 세리머니, "제, 제가요…?" |
| 허세 | 한쪽 눈썹을 올리고 씩 웃음 | 가슴 펴기, 손가락 총 |
| 느긋 | 반쯤 감은 눈 | 하품, "괜찮아, 괜찮아" |

- 나누는 기준: **강점은 몸과 소품으로, 성격은 얼굴과 행동으로** 드러냅니다.
- 추가로 필요한 그림: 성격마다 표정 2~3개와 세리머니 동작 1~2칸입니다.

## 시안에 그릴 것
팀 색은 초록(주 색)과 흰색(부 색)입니다. 선수마다 자세 4개(서 있기, 수비 준비, 타격 준비, 달리기)를 그립니다.

| 줄 | 선수 | 확인할 것 |
|---|---|---|
| 1 | A 파워(우타), B 주력(좌타), C 선구안(우타) | 강점을 짐작할 수 있는지 |
| 2 | 파워 강점 선수 4명(체형·소품·개인 특징·얼굴이 규칙대로 다르게) | 같은 강점끼리 구별되는지 |

비교 화면에는 지금 그림과 새 시안을 **경기장 크기**와 **카드 크기**로 나란히 놓습니다.
