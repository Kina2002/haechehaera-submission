게임 실행
  index.html을 Chrome 또는 Edge에서 여세요.
  게임실행.cmd를 두 번 클릭해도 실행됩니다.
  그림과 글꼴을 전부 포함하므로 실행에 설치나 인터넷 연결이 필요하지 않습니다.

플레이
  저장칸 선택 → 팀 이름·배색 → 최초 12명 이름·번호 확인 → 출전 9명 편성 → 경기 시작.
  경기에서는 공격·수비 버튼으로 지시합니다. 자동 경기와 남은 경기 스킵도 가능합니다.
  선수·훈련·영입·시설·재정과 계약·구단 소식·기록·설정은 상단 메뉴에서 선택합니다.
  저장은 현재 브라우저와 주소에 묶입니다. 다른 컴퓨터나 주소로 옮길 때 설정에서 백업 파일을 내려받으세요.

선수 생성 규칙
  초기 12명: 일반 강점 60~80, 야구센스 강점 55~65, 약점 1~25, 나머지 7개 20~55.
  영입: 야구센스 포함 9개 능력 각각 10~70, 선수당 0.1% 확률로 하나만 80~100.
  스태미나: 초기·영입 모두 별도 40~60, 특별 능력 추첨에서 제외.
  기존 선수와 이미 생성된 후보는 유지하며 이후 새로 생성할 때 적용합니다.

구단 사건 연출
  경기 밖 사건 10종을 실제 선수 외형과 유니폼으로 재생합니다(9종 약10초, 어린이 공 선물 약6.6초).
  새 사건은 결과 화면에서 자동으로 알리고, 실제 팬·애정도 변화를 확인한 뒤 닫습니다.
  결과 바로 보기, 구단 소식에서 다시 보기, 설정에서 미리보기를 제공합니다.
  재생 때문에 수치가 중복 적용되지 않으며, 미확인 상태도 저장됩니다.
  후보 선수 응원가는 해당 경기 미출전 선수(애정도 +3), 성의 없는 인터뷰는 패배 경기 출전 선수(팬 -12)에게만 발생합니다.
  길 잃은 어린이 돕기는 팬 +20이며, 신규 3종은 능력치나 자금을 바꾸지 않습니다.

개발용 파일
  src/club-events.js, src/club-events.css: 사건 알림·10종 애니메이션·확인 상태·다시 보기.
  src/game.js: 기본 경기 규칙과 화면, 저장 연결.
  src/extensions.js: 경영·계약·캐릭터·판정·경기 연출 등 현재 통합 기능.
  src/character-data.js, src/frame-bounds.js: 캐릭터 데이터와 프레임 위치.
  src/storage.js, src/storage-ui.js: 저장 보호와 복구 안내.
  assets/: PNG 87개, 글꼴 2개, 무결성 확인 목록.
  dev.html: 외부 자산을 사용하는 개발용 실행 화면.
  build.py: src와 assets로 단일 index.html 생성. 이전 게임 파일이나 다른 프로젝트를 참조하지 않음.
  tools/import_handoff.py: 최초 추출 작업에만 사용한 도구. 수정한 코드를 초기화하므로 다시 실행하지 마세요.

MLB 진출
  선수 관리에서 제안을 확인하고 직접 도전합니다. 기록실에 진출 명단과 누적 이적료를 보관합니다.
  기본 조건: 출전 5경기, 타격 또는 투구 3능력 평균 75 이상, 계약 중, 구단 10명 이상.
  시험값: 성공률 35~85%, 성공 이적료 5천만~1억 5천만 원, 실패 애정도 -20, 재도전 대기 3경기.
  성공 후 최소 9명을 유지하고 선수 기록·당시 모습·마지막 경기 자료를 보존합니다.
  src/mlb.js·mlb.css와 기능별 문서 F25를 참고하세요. 검사 도구는 tests.html에만 있습니다.
