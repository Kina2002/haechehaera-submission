# F22 설정과 미리보기

팀 정보·경기 속도·효과음·시험 수치·그림을 확인합니다.

**분야:** 설정과 실행  
**상태:** 현재 구현 · 시험값 포함  
**기준:** 2026-10-07 로컬 구현본

[전체 기능 목차](README.md)

## 찾는 곳

상단 설정 · 홈의 설정·연출 미리보기

## 화면에서 할 일

1. 팀 이름과 배색, 속도 1·2·3배, 전체 소리 켜짐/꺼짐을 바꿉니다.
2. 시험 수치 조정에서 가격·체력·계약 등 값을 확인합니다.
3. 필요하면 선수 외형·움직임·리액션과 글꼴 라이선스를 봅니다.

배경음악과 효과음·목소리는 각각 0~100%로 조절합니다. [F27 사운드](F27-상황별-사운드.md)를 참고하세요.

## 적용 규칙

- 팀 정보 변경은 현재 구단에 적용하며 이름 1~12자 규칙을 유지합니다.
- 시험 설정은 이후 행동에 적용합니다. 이미 지급한 시작 자금은 다시 지급하지 않습니다.
- 확률은 0~1, 스태미나 상한은 1~100 정수, 계약 기간은 1~100 정수로 검사합니다.
- 하단의 심판 판정 미리보기·v14 그림 점검 등의 검사 도구는 플레이 화면에서 제거했습니다.
- 설정 안의 연출/외형 미리보기는 남아 있습니다. 자동검사 도구는 별도의 tests.html이며 실제 구단 저장을 읽거나 쓰지 않습니다.

## 막히는 조건과 예외

- 경기 중 팀 이름·배색·운영 수치 변경을 제한합니다.
- 입력 범위가 잘못되면 시험 설정을 저장하지 않습니다.

## 직접 확인할 항목

- [ ] 게임 아래에 검사 도구가 없는지 봅니다.
- [ ] 설정에서 경기 속도와 효과음을 바꿀 수 있는지 봅니다.

## 현재 확인된 범위

개발 화면과 단일 실행 파일에서 하단 도구 0개 확인. 검사 페이지의 저장 분리 확인. 설정 입력 범위는 코드 확인입니다.

자동검사 통과와 사용자 확인은 구별합니다. 위 체크박스는 직접 플레이하며 확인할 때 표시합니다.
