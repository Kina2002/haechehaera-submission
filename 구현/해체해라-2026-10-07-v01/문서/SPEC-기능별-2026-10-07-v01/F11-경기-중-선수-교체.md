# F11 경기 중 선수 교체

후보 선수를 넣어 체력과 능력을 보완합니다.

**분야:** 경기  
**상태:** 현재 구현 · 시험값 포함  
**기준:** 2026-10-07 로컬 구현본

[전체 기능 목차](README.md)

## 찾는 곳

경기 화면의 선수 교체

## 화면에서 할 일

1. 투구와 리액션이 끝난 뒤 선수 교체를 누릅니다.
2. 나갈 선수와 들어올 후보의 능력·체력을 비교합니다.
3. 후보를 선택한 뒤 경기 재개를 누릅니다.

## 적용 규칙

- 후보는 나가는 선수의 타순과 수비 위치를 이어받습니다.
- 내려간 선수는 같은 경기에 다시 출전할 수 없습니다.
- 이미 발생한 개인 기록은 원래 선수에게 남습니다.
- 상대 투수는 현재 체력 30% 이하일 때 안전한 타석 종료 시점에 자동 교체합니다. 체력·투구 능력이 좋은 미출전 후보를 고릅니다.
- 상대 후보가 소진되면 내려간 투수를 다시 넣지 않습니다.

## 막히는 조건과 예외

- 공 처리·리액션·수비 이동 중에는 교체하지 않습니다.
- 선발로 출전 중이거나 이미 사용한 후보를 다시 넣을 수 없습니다.

## 직접 확인할 항목

- [ ] 교체 후 타순·포지션이 유지되는지 봅니다.
- [ ] 나간 선수를 다시 넣을 수 없는지 봅니다.

## 현재 확인된 범위

우리 팀 교체·재출전 차단 검사 통과. 상대 자동 교체는 관련 코드와 기존 검사 항목으로 추적하며, 별도 교체·팀 흐름 검사는 이번 기록에 포함되지 않습니다.

자동검사 통과와 사용자 확인은 구별합니다. 위 체크박스는 직접 플레이하며 확인할 때 표시합니다.
