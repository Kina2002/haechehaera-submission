# F28 첫 경기 튜토리얼

실제 게임 버튼을 누르며 첫 경기를 배우는 안내입니다. 사용자가 확인한 ‘버튼 옆 안내’ 시안을 바탕으로 구현했습니다.

**분야:** 시작과 저장 · 경기 · 구단 운영

**상태:** 현재 구현

**기준:** 2026-10-08

[전체 기능 목차](README.md)

## 시작과 다시 보기

- 새 게임에서 팀을 만들면 해당 저장칸에 안내 진행 상태를 생성합니다.
- 기존의 선수 12명 지급·이름·등번호 입력을 마치고 라인업에 도착하면 첫 안내가 뜹니다.
- 기존 저장에는 자동으로 안내를 추가하지 않습니다. **설정 → 첫 경기 안내 → 튜토리얼 다시 보기**로 시작할 수 있습니다.
- 다시 보기는 현재 구단으로 진행합니다. 선수·자금·승패·기록을 초기화하거나 연습용으로 복제하지 않습니다.
- 진행 중인 경기가 있으면 경기 진행 방식 안내부터, 경기 전이나 경기 종료 후에는 라인업부터 다시 시작합니다.

## 단계와 완료 행동

| 단계 | 안내 | 진행 행동 |
| --- | --- | --- |
| 1 / 5 | 선발 9명·타순·수비 위치, 후보 3명 | 실제 **자동 배치**가 성공해야 다음 단계로 이동 |
| 2 / 5 | 편성으로 경기 시작, 반자동·자동·스킵 | 실제 경기 시작 후 입장 연출이 끝나면 **반자동으로 시작** 선택 |
| 3 / 5 | 컨택·풀스윙·참아 | 실제 공격 지시 하나를 선택 |
| 4 / 5 | 남은 체력, 후보, 재출전 제한 | 실제 **선수 교체** 창을 열어 확인. 선수 교체 자체는 필수가 아님 |
| 5 / 5 | 결과·결산, 다음 경기 운영비, 훈련·영입 비용 | 경기 종료 후 **구단 홈으로** 이동하고 **훈련 보기·영입 보기·안내 마치기** 중 하나 선택 |

- 우리 팀 수비부터 시작하면 3단계에서 수비 위치 안내를 먼저 보여 줍니다. 수비 지시 하나를 선택한 뒤 우리 공격 차례가 될 때 타격 안내가 이어집니다.
- 수비 위치는 해당 타석 동안 유지됩니다. 투구·리액션 진행 중에 안내를 끼워 넣지 않습니다.
- 타격 안내를 기다리는 동안 자동경기로 전환하면 지시 안내는 반자동 복귀를 기다립니다. 자동 진행이나 경기 스킵으로 종료되면 마지막 운영 안내로 연결됩니다.
- 자동 배치는 기존 편성을 실제로 바꿉니다. 경기 시작은 실제 계약·편성·운영 조건을 검사합니다.
- 공격 지시는 실제 공을 진행합니다. 지시가 안타·홈런을 보장하지 않으며, 안내를 위해 승패·능력치·난수를 바꾸지 않습니다.
- 교체 창을 닫으면 경기는 정지 상태입니다. **경기 재개**를 눌러 계속합니다. 실제 교체 시 나간 선수는 해당 경기 재출전이 불가능합니다.
- 다음 경기 운영비를 홈에서 강조합니다. 훈련시설 건설·훈련·영입·계약을 강제로 실행하지 않습니다.
- 안내 사이에 남은 경기를 스킵해서 아직 보지 않은 단계가 있어도, 경기 종료 후 마지막 운영 안내로 연결됩니다.

## 안내 표시와 정지 규칙

- 대상 버튼·영역에 노란 테두리를 두르고 나머지 화면을 어둡게 합니다. 안내 카드는 버튼 옆 또는 위·아래 공간에 배치합니다.
- 게임의 기존 PC 화면 너비는 유지합니다. 좁은 창에서는 안내 카드를 창 안에 배치하고, 대상 버튼이 보이도록 가로·세로 스크롤을 맞춥니다. 창 크기가 바뀌면 위치를 다시 맞춥니다.
- 안내 중에는 해당 단계의 대상 버튼과 안내 버튼만 사용할 수 있습니다. Tab으로 이동하고 Enter로 선택할 수 있습니다.
- 경기 중 안내 카드가 떠 있는 동안 투구·애니메이션·지시 시간·체력·경기 난수 진행을 멈춥니다. 카드에는 **경기 · 지시 시간 정지**를 표시합니다.
- 입장 연출·구단 사건·MLB 알림·업적 알림·다른 대화창과 동시에 안내를 띄우지 않습니다.
- 대상 행동을 선택하면 정지를 풀고 기존 경기 동작을 실행합니다. 새 공의 반자동 지시 시간은 기존 10초 규칙을 사용합니다.
- 다른 탭으로 이동하면 기존 경기 일시정지 규칙을 유지합니다. 안내를 닫았다는 이유로 숨겨진 탭에서 경기를 재개하지 않습니다.

## 건너뛰기와 저장

- 모든 안내에 **안내 건너뛰기**가 있습니다. Esc로도 건너뛸 수 있습니다.
- 건너뛰기·완료 상태는 해당 구단에 저장되어 다음 접속 때 처음부터 다시 뜨지 않습니다.
- 진행 중인 안내는 저장칸별로 이어지며, 백업에도 포함됩니다. 새로고침 후 진행 중 경기는 기존 규칙에 따라 정지 상태로 불러옵니다.
- 안내 전에 유저가 일시정지한 상태였다면 건너뛰기로 그 정지를 해제하지 않습니다.
- 알 수 없는 버전이나 손상된 안내 데이터는 선택적 안내 데이터만 제거합니다. 기존 선수·경기 저장을 복구 불가로 만들지 않습니다.

## 직접 확인할 항목

- [ ] 처음 플레이할 때 자동 배치부터 경기 시작까지 안내가 이해되는지 봅니다.
- [ ] 수비부터 시작해도 우리 공격 때 타격 안내가 나오는지 봅니다.
- [ ] 안내를 읽는 동안 지시 시간이 줄지 않는지 봅니다.
- [ ] 교체하지 않고 창만 확인해도 다음 안내로 이동하는지 봅니다.
- [ ] 건너뛰기·새로고침·설정에서 다시 보기가 자연스러운지 봅니다.
- [ ] 휴대전화 화면에서 안내와 대상 버튼이 겹치지 않는지 봅니다.

사용자의 시안 선호 확인과 실제 게임 플레이 확인은 구분합니다. 위 체크박스는 사용자가 플레이하며 확인할 때 표시합니다.

## 개발 참고

현재 검증: 전체 Node 검사 150개(튜토리얼 11개 포함), 실제 버튼 진행 10항목과 안내 중 상태 고정 168회, 완료 상태 백업 확인. 기존 브라우저 흐름 34항목·경기 규칙 52개·계약 규칙 17개도 통과했습니다. 관련 결과는 `tests/tutorial-flow-20261008-v01.json`에 보관합니다. 실제 교체 강요 검사는 다운로드한 시험 구단 백업으로 재검증했으며, 상대 투수 자동 교체를 제외합니다.

최신 웹 배포 파일에서도 새로고침·건너뛰기·설정 다시 보기, 390×844 창의 안내/대상 버튼 표시와 겹침 없음, 화면 오류 없음(자금 3,000만원 유지)을 확인했습니다. `tests/tutorial-ui-20261008-v01.json`과 `tests/tutorial-desktop-20261008-v01.jpg`, `tests/tutorial-narrow-20261008-v01.jpg`에 결과를 보관합니다.

- `src/tutorial.js` — 단계 규칙, 저장 상태 검증, 실제 버튼 연동, 정지와 포커스 제어
- `src/tutorial.css` — 대상 강조와 안내 카드, 좁은 화면 대응
- `tests/tutorial.test.cjs` — 단계·저장 호환·실제 행동 성공/실패 검사
- `tests/tutorial-qa.js` — 실제 저장과 분리한 브라우저 진행 검사
