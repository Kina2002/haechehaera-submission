# F24 실행 방식과 화면 자산

그림과 글꼴이 포함된 PC 브라우저 게임을 실행합니다.

**분야:** 설정과 실행  
**상태:** 현재 구현  
**기준:** 2026-10-07 로컬 구현본

[전체 기능 목차](README.md)

## 찾는 곳

index.html 또는 게임실행.cmd · 개발 화면 dev.html

## 화면에서 할 일

1. Chrome 또는 Edge에서 index.html을 엽니다.
2. 팀을 만들고 경기·선수·운영 기능을 사용합니다.
3. 개발 시 src와 assets를 수정한 뒤 build.py로 단일 파일을 생성합니다.

## 적용 규칙

- 단일 실행 파일에 그림 PNG 87개와 글꼴 2개를 포함합니다. 실행에 별도 설치나 인터넷 연결이 필요하지 않습니다.
- 큰 글씨는 Neo둥근모, 세부 글씨는 갈무리9를 사용하고 라이선스 안내를 보관합니다.
- 캐릭터는 6체형이며 경기 중 작은 동작형과 경기 밖 상세형을 구분합니다. 외형 파츠 없음도 지원합니다.
- 포수의 쪼그린 자세는 그 팀이 수비 중일 때만 씁니다. 공격 중인 팀의 포수가 주자로 베이스에 있으면 다른 주자와 같은 모습으로 그립니다(2026-11-05 수정).
- 경기장 원근(2026-11-05): 멀수록 작게 그립니다. 가장 먼 외야는 약 0.55배, 홈 근처는 약 1.5배입니다(이전 0.76~1.56배). 심판도 같은 비율을 따릅니다.
- 모든 선수와 심판 발밑에 넓고 부드러운 그림자와 발 바로 아래의 진한 그림자를 그려 땅에 붙어 보이게 합니다. 외야 쪽 선수는 채도를 최대 30% 낮춰 거리감을 줍니다.
- 경기장 선수에는 얇은 어두운 외곽선을 넣어 잔디와 비슷한 팀 색도 잘 보이게 합니다.
- 서 있는 자세: 수비수는 수비 준비 자세, 공격 팀 주자는 리드 자세, 투수는 투구 준비 자세입니다. 땅볼을 잡은 수비수는 플레이 후반에 공을 들고 선 자세로 바뀝니다.
- 현재 PC 중심 화면으로 최소 너비 1,080px입니다. 좁은 패널에서는 가로 스크롤 또는 넓은 브라우저 창을 사용합니다.
- 이전 프로젝트 없이 현재 src·assets·build.py로 실행 파일을 다시 만들 수 있습니다.

## 막히는 조건과 예외

- 파일 내용을 보여주는 단순 미리보기 대신 자바스크립트가 실행되는 브라우저로 열어야 합니다.
- 모바일 최적화·이번 변경의 공개 사이트 배포는 현재 구현본 범위에 포함되지 않습니다.

## 직접 확인할 항목

- [ ] 게임 로딩 뒤 저장 선택과 캐릭터가 정상 표시되는지 봅니다.
- [ ] 하단 검사 버튼이 없고 같은 파일을 다시 만들어도 내용이 일치하는지 확인합니다.

## 현재 확인된 범위

단일 파일 실행 오류 0, 원본 PNG 87개 바이트 일치, 빌드 재생성 일치. 216자세·126체형/파츠 검사 오류 0. 모든 조합의 눈으로 보는 검사 완료를 뜻하지 않습니다.

자동검사 통과와 사용자 확인은 구별합니다. 위 체크박스는 직접 플레이하며 확인할 때 표시합니다.
