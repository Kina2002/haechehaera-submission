# F23 백업 불러오기와 저장 복구

파일로 구단을 옮기고 손상된 저장의 원본을 보호합니다.

**분야:** 시작과 저장  
**상태:** 현재 구현  
**기준:** 2026-10-07 로컬 구현본

[전체 기능 목차](README.md)

## 찾는 곳

저장 선택·설정의 백업/파일 불러오기 · 오류 시 저장 안내

## 화면에서 할 일

1. 다른 주소나 컴퓨터로 옮기기 전에 백업 JSON 파일을 내려받습니다.
2. 대상 저장칸에서 파일 불러오기를 누르고 확인합니다.
3. 손상 안내가 나오면 최근 저장본 복구 또는 원본 내려받기/원본 보관 후 새로 시작을 사용합니다.

## 적용 규칙

- 불러올 파일은 저장 버전·구단·선수·기록·진행 경기 형식을 검사합니다. 크기는 최대 12MiB입니다.
- 파일을 확인하기 전에는 기존 저장칸을 대체하지 않습니다. 잘못된 파일과 취소는 기존 진행을 유지합니다.
- 최근 정상 저장본을 따로 보관합니다. 현재 저장을 읽지 못하면 이 저장본으로 복구합니다.
- 복구 가능한 저장본이 없으면 자동 저장을 멈추고 손상 원본을 그대로 유지합니다.
- 원본 보관 후 새로 시작은 확인을 거치며, 원본을 보관할 공간이 부족하면 기존 저장을 유지합니다.
- 복구용 최근 저장본은 파일 백업과 다릅니다. 다른 주소로 옮기려면 파일 백업을 사용합니다.

## 막히는 조건과 예외

- 지원하지 않는 저장 버전·잘못된 형식·너무 큰 파일은 불러오지 않습니다.
- 저장 공간 부족 또는 접근 차단 때 기존 저장을 빈 데이터로 덮어쓰지 않습니다.

## 직접 확인할 항목

- [ ] 백업 파일을 다른 빈 저장칸으로 불러왔을 때 구단·선수·자금·기록이 같은지 봅니다.
- [ ] 파일 불러오기 확인 창에서 취소하면 기존 구단이 유지되는지 봅니다.

## 현재 확인된 범위

저장 보호 9/9 검사 통과: 손상 JSON·검증 실패·최근 정상본·원본 보관·공간 부족·접근 차단 포함. 실제 사용자 저장을 손상시키는 검사는 하지 않습니다.

자동검사 통과와 사용자 확인은 구별합니다. 위 체크박스는 직접 플레이하며 확인할 때 표시합니다.
