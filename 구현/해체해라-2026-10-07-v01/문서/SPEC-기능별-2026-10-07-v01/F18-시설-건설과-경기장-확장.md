# F18 시설 건설과 경기장 확장

훈련·복지·수익·팬 시설과 건물 자리를 관리합니다.

**분야:** 구단 운영  
**상태:** 현재 구현 · 시험값 포함  
**기준:** 2026-10-07 로컬 구현본

[전체 기능 목차](README.md)

## 찾는 곳

상단 시설 · 홈의 구단 시설

## 화면에서 할 일

1. 전체/훈련/복지/수익/팬 카테고리로 시설을 봅니다.
2. 시설의 효과·건설비·경기당 유지비를 비교하고 건설합니다.
3. 경기장을 확장해 건물 자리와 좌석을 늘립니다.

## 적용 규칙

- 시작 시설 0개, 경기장 1등급, 건물 한도 5개입니다. 최대 5등급입니다.
- 건물 한도=5+(등급−1)×3입니다. 좌석은 표시 기준 등급×2,000석입니다.
- 현재 14종: 훈련 5개·복지 5개·수익 3개·팬 1개입니다.
- 시험값은 건설 1,000만원/개, 유지비 150만원/개/경기입니다. 확장비는 현재 등급×2,500만원입니다.
- 같은 종류의 시설은 중복 건설하지 않습니다.

## 막히는 조건과 예외

- 건물 한도·자금 부족·이미 건설한 시설·진행 중 경기에는 건설을 제한합니다.
- 경기장 5등급에서는 더 확장하지 않습니다.
- 철거·교체·환불·건설 소요시간은 현재 제공하는 운영 기능에 포함되지 않습니다.

## 직접 확인할 항목

- [ ] 시설 건설 뒤 인원과 무관하게 건물 수·자금·유지비가 바뀌는지 봅니다.
- [ ] 경기장 확장 뒤 등급·좌석·건물 한도가 증가하는지 봅니다.

## 현재 확인된 범위

시작 시설·자금·선수와 시설 운영비 합산 검사 통과. 건설/확장 버튼은 코드 확인과 직접 확인 항목입니다.

자동검사 통과와 사용자 확인은 구별합니다. 위 체크박스는 직접 플레이하며 확인할 때 표시합니다.
