# F12 일시정지 자동 경기와 스킵

상황에 맞게 경기 진행 방식을 바꿉니다.

**분야:** 경기  
**상태:** 현재 구현  
**기준:** 2026-10-08 로컬 구현본

[전체 기능 목차](README.md)

## 찾는 곳

경기 상단의 일시정지·자동 경기·자동 배속·남은 경기 스킵

## 화면에서 할 일

1. 일시정지/경기 재개로 멈추거나 이어갑니다.
2. 자동 경기/반자동으로를 눌러 진행 방식을 바꿉니다.
3. 자동경기에서 상단 **자동 배속 → 2배속**을 선택합니다. 1배속·3배속도 같은 곳에서 선택할 수 있습니다.
4. 남은 경기 스킵으로 결과와 요약까지 처리합니다.

## 적용 규칙

- 직접 지시·자동 경기·스킵은 같은 판정 규칙을 사용합니다.
- 자동은 공과 선수의 움직임을 보여주며 경기 상단과 설정에서 1·2·3배속을 선택합니다. 두 곳은 같은 저장 값을 사용합니다.
- 자동 배속은 투구·타격·주루 애니메이션과 수비 위치 이동, 결과·멘트 표시, 다음 공 대기에 적용합니다. 2배속은 해당 시간을 약 절반으로 줄입니다.
- 배속을 바꾸면 진행 중인 투구 애니메이션은 이어가고 다음 투구부터 새 움직임 속도를 사용합니다. 결과·멘트·대기는 현재 선택한 배속으로 진행합니다.
- 반자동에서는 배속 선택을 비활성화하고 기본 속도로 진행합니다. 직접 지시 시간 10초와 경기 입장 연출은 배속으로 줄이지 않습니다.
- 일시정지는 배속과 관계없이 움직임·결과·멘트 대기를 멈춥니다.
- 심판 음성과 효과음은 원래 음높이로 재생하며 투구·타격·판정 시점에 맞춥니다. 배속은 판정 확률·체력 소모·개인 기록·정산 수치를 바꾸지 않습니다.
- 스킵도 남은 경기의 체력·교체·본헤드·개인 기록·계약·자금을 처리합니다.
- 화면을 떠나거나 브라우저에서 경기를 복구하면 진행 중인 경기를 일시정지합니다.
- 이미 끝난 경기의 보상과 결산은 다시 지급하지 않습니다.

## 막히는 조건과 예외

- 진행 중에는 자금 영입·훈련·시설·계약 등 운영 변경이 제한됩니다.
- 스킵 처리 중에는 중복 실행을 막습니다.

## 직접 확인할 항목

- [ ] 자동↔반자동 전환 후 점수와 타순이 이어지는지 봅니다.
- [ ] 경기 상단에서 2배속을 선택하고 결과·멘트·다음 공 대기가 빨라지는지 봅니다.
- [ ] 일시정지·재개 후 배속이 유지되고 설정에도 같은 값이 표시되는지 봅니다.
- [ ] 스킵 후 결과를 다시 열어도 자금·승수·계약이 두 번 바뀌지 않는지 봅니다.

## 현재 확인된 범위

기존 자동 시뮬레이션 3경기 완료·규칙 위반 0과 보상 중복 방지 검사에 더해, 배속 단위 검사 7개 및 전체 단위 검사 134개를 통과했습니다. 투구를 한 번만 판정하고, 결과·멘트까지 포함한 2배속 진행 시간이 기본의 약 절반이며, 일시정지·반자동 10초 지시·심판 소리 시점이 유지됨을 확인했습니다.

브라우저에서 상단 2배속 선택·반자동 비활성화·모드 전환 후 값 유지·정지 중 기록 유지·재개 후 새 기록·설정 동기화·음원 시점·오류 없음의 8항목을 확인했습니다. [검사 기록](../../tests/auto-speed-browser-checks-20261008-v01.json)과 [2배속 경기 화면](../../tests/auto-speed-20261008-v01.png)에 보관합니다. 장시간 켜놓는 플레이는 별도입니다.

자동검사 통과와 사용자 확인은 구별합니다. 위 체크박스는 직접 플레이하며 확인할 때 표시합니다.
