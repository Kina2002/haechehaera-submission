# F01 저장칸과 이어하기

두 구단의 진행을 따로 보관하고 이어갑니다.

**분야:** 시작과 저장  
**상태:** 현재 구현  
**기준:** 2026-10-07 로컬 구현본

[전체 기능 목차](README.md)

## 찾는 곳

첫 화면의 저장 선택 · 상단 저장 버튼 · 홈의 저장칸 보기

## 화면에서 할 일

1. 빈 저장칸에서 새 게임을 누릅니다.
2. 사용 중인 칸에서는 불러오기·백업·파일 불러오기·삭제를 선택합니다.

## 적용 규칙

- 저장칸은 2개이며 선수·자금·기록·진행 경기는 각 구단에 따로 저장합니다.
- 진행 중인 경기를 불러오면 일시정지 상태로 시작합니다. 경기 재개를 눌러 이어갑니다.
- 저장 삭제와 처음부터 다시 하기는 확인 창을 거칩니다. 취소하면 그대로 유지합니다.

## 막히는 조건과 예외

- 팀이 없는 칸에서는 팀 백업을 만들 수 없습니다.
- 브라우저나 접속 주소가 바뀌면 다른 저장 공간을 사용합니다.

## 직접 확인할 항목

- [ ] 두 저장칸에 다른 이름의 구단을 만들고 각각 불러왔을 때 선수와 자금이 섞이지 않는지 봅니다.
- [ ] 삭제 확인에서 취소했을 때 구단이 유지되는지 봅니다.

## 현재 확인된 범위

두 슬롯 직렬화·복원 자동검사 통과. 삭제 취소와 주소 간 이동은 직접 확인 항목입니다.

자동검사 통과와 사용자 확인은 구별합니다. 위 체크박스는 직접 플레이하며 확인할 때 표시합니다.
