**최초 작성일:** 2026-10-07 · **현황 정리:** 2026-11-16

**문서 폴더 버전:** v01 (경로 유지)

**기준:** 제공된 v27에서 이어온 현재 로컬 구현본

2026-11-18에 공개 버전 **28**을 [1차 MVP 기준본](../../../../기획참고/1차-MVP-2026-11-18-v01/README.md)으로 기록하고 새 버전 재설계로 전환했습니다. 이 폴더는 기존 기능 명세로 보존하며, 새 버전 채택 범위는 별도로 정합니다. 완료·미구현·보류 항목은 [지금 먼저 볼 것](../../../../지금-먼저-볼-것.md), 배포 이력은 [배포 안내](../../../../DEPLOYMENT.md)를 확인합니다. P 문서 중에도 이미 구현한 규칙이 있으므로 작성 시점과 최신 상태를 함께 봅니다.

## 문서 읽는 기준

- **현재 구현:** 코드에 있는 기능입니다.
- **시험값 포함:** 현재 플레이에 사용하는 금액·확률·체력 수치로, 이후 조정할 수 있습니다.
- **직접 확인할 항목:** 사용자가 플레이하며 확인할 체크리스트입니다. 자동검사 결과를 사용자 확인으로 간주하지 않습니다.
- 변경을 요청할 때는 **F10 수비 지시**처럼 기능 번호와 이름을 함께 말하면 됩니다.

## 확인 기록과 범위

2026-11-16에는 공개 사이트의 한 시즌 10경기·주요 경영 흐름을 확인했고, 홈 대출 버튼 및 A10 수정도 시험 구단으로 실제 버튼 동작을 확인했습니다. A10 관련 자동 검사 31개 통과. 세부·한계는 [구현 기록](../../../../개발일지/02-게임-버전/시즌-시스템-구현-기록.md)과 [P28](P28-다섯-유저-실제-게임-플레이-시험.md)을 봅니다. 아래 표는 **이전 시점의 검사 기록**이며, 현재 전체 검사 결과나 모든 기기의 품질 보증으로 사용하지 않습니다. 내부 교체 검사 4개에 남은 DH 이전 기대값은 정리 대기입니다.

| 검사 | 결과 |
| --- | --- |
| 경기·운영 규칙 | 52 / 52 통과 |
| 심판 판정 연결 | 16 / 16 통과 |
| 계약과 이적 | 15 / 15 통과 |
| 저장 보호 | 9 / 9 통과 |
| 자동 경기 | 3경기 완료 · 규칙 위반 0 |

| 자산과 실행 파일 | 원본 PNG 87개 바이트 일치 · 단일 파일 재생성 일치 |
| 경기 기록 색상 · 2026-10-08 | 단위 5개 포함 전체 139개 · 브라우저 색상 10/10 · 기존 흐름 34/34 · 경기 규칙 52/52 · 계약 17/17 |

자동검사는 아웃·주자·득점·타순·기록과 일부 그림 좌표를 확인합니다. 모든 동작의 자연스러움, 모든 배색·파츠 조합, 장기 경영 난이도와 모바일 품질까지 확인한 결과는 아닙니다.
