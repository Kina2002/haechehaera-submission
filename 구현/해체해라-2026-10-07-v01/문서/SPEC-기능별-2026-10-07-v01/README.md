# 해체해라 기능별 SPEC

기능 하나당 Markdown 파일 하나로 나누었습니다. 목록에서 기능을 고르면 찾는 곳·사용 순서·규칙·제한·직접 확인할 항목을 볼 수 있습니다.

**작성일:** 2026-10-07  
**문서 버전:** v01  
**기준:** 제공된 v27에서 이어온 현재 로컬 구현본

## 문서 읽는 기준

- **현재 구현:** 코드에 있는 기능입니다.
- **시험값 포함:** 현재 플레이에 사용하는 금액·확률·체력 수치로, 이후 조정할 수 있습니다.
- **직접 확인할 항목:** 사용자가 플레이하며 확인할 체크리스트입니다. 자동검사 결과를 사용자 확인으로 간주하지 않습니다.
- 변경을 요청할 때는 **F10 수비 지시**처럼 기능 번호와 이름을 함께 말하면 됩니다.

## 기준 숫자

아래는 기본값입니다. 구단 시험 설정을 바꾸었다면 현재 구단의 수치는 다를 수 있습니다.

| 항목 | 기본값 | 상태 |
| --- | --- | --- |
| 시작 선수 / 보유 한도 / 출전 | 12명 / 35명 / 9명 | 현재 규칙 |
| 저장칸 | 2개 | 현재 규칙 |
| 기본 경기 / 연장 최대 | 5이닝 / 7회 | 현재 규칙 |
| 콜드게임 | 3회 종료부터 양 팀 공격 완료 후 10점 차 이상 | 현재 규칙 · 끝내기 없음 |
| 지시 / 리액션 | 최대 10초 / 5초 | 현재 규칙 |
| 본헤드 한도 | 우리 팀 같은 회 초·말 합산 3건 | 현재 규칙 |
| 시작 자금 | 3,000만원 | 시험값 |
| 시설 건설 / 경기 유지비 | 1,000만원 / 150만원 | 시험값 |
| 경기 완료 / 득점 / 승리 보너스 | 350만원 / 1점당 80만원 / 추가 600만원 | 시험값 |
| 기본 계약 | 5경기 | 시험값 |
| 고급여 상승 | 희망급여 120% 이상, 30% 확률 +1 | 시험값 |
| 저급여 감소 / 협상 감소 | 희망급여 90% 이하 매 경기 −3 / 80% 이하 제안도 수락, 매 협상 90% 확률 −30 한 번 | 현재 적용 규칙 |
| 상대 투수 교체 | 체력 30% 이하, 안전한 타석 종료 시점 | 시험값 |
| 경기 팬 사건 | 32% 확률, 조건에 맞는 10종 중 하나 | 시험값 |

## 현재 확인된 범위

| 검사 | 결과 |
| --- | --- |
| 경기·운영 규칙 | 52 / 52 통과 |
| 심판 판정 연결 | 16 / 16 통과 |
| 계약과 이적 | 15 / 15 통과 |
| 저장 보호 | 9 / 9 통과 |
| 자동 경기 | 3경기 완료 · 규칙 위반 0 |
| 캐릭터 | 216자세 · 126체형/파츠 검사 오류 0 |
