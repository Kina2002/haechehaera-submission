# F15 경기 결과와 기록실

경기의 흐름과 개인 기록·구단 결산을 다시 봅니다.

**분야:** 경기  
**상태:** 현재 구현  
**기준:** 2026-10-08 콜드게임 결과 표시

[전체 기능 목차](README.md)

## 찾는 곳

경기 종료 결과 · 상단 기록 · 홈의 기록실

## 화면에서 할 일

1. 최종 점수와 승패무를 봅니다.
2. 이닝별 득점과 주요 사건 요약을 펼칩니다.
3. 우리 선수 타격 기록과 자금 결산을 확인합니다.

## 적용 규칙

- 경기 점수·안타·본헤드·투구 수·이닝별 흐름과 주요 사건을 보관합니다.
- 현재 경기 이력은 최근 20경기를 보관합니다.
- 콜드게임은 결과 화면과 기록실에 콜드승·콜드패, 종료 회차와 점수 차를 표시합니다. 기록·백업에도 종료 사유를 보존합니다.
- 콜드승·콜드패도 일반 경기와 같은 승패·보상·급여 결산을 사용합니다. 기존 종료 경기의 결과는 다시 계산하지 않습니다.
- 타율=안타/타수, 출루율=(안타+볼넷+사구)/(타수+볼넷+사구+희생플라이), 장타율=총루타/타수입니다.
- 볼넷·사구·희생플라이는 타석에 포함하고 타수에서 제외합니다. 폭투와 포일의 기록 주체를 구별합니다.
- 경기 뒤 이적한 선수도 이미 발생한 경기 기록과 결과 장면에 남습니다.

## 막히는 조건과 예외

- 기록이 없을 때는 첫 경기 안내를 표시합니다.
- 결과 화면을 다시 열거나 스킵을 반복해도 보상을 추가 지급하지 않습니다.

## 직접 확인할 항목

- [ ] 점수와 이닝별 득점 합계가 맞는지 봅니다.
- [ ] 볼넷은 늘었지만 타수가 늘지 않는지 개인 기록에서 봅니다.

## 현재 확인된 범위

만루 볼넷·비강제 진루·병살 득점·만루 홈런·희생플라이·도루 실패 타순·보상 중복 검사 통과.

자동검사 통과와 사용자 확인은 구별합니다. 위 체크박스는 직접 플레이하며 확인할 때 표시합니다.
