# F04 구단 홈

경기와 구단 운영 화면으로 이동하고 구단 상황을 봅니다.

**분야:** 시작과 저장  
**상태:** 현재 구현  
**기준:** 2026-11-13 A6 운영비 예상 반영

[전체 기능 목차](README.md)

## 찾는 곳

상단 구단 홈

## 화면에서 할 일

1. 첫 준비가 끝났다면 경기 시작을 누릅니다.
2. 진행 중인 경기에는 경기 이어하기를 사용합니다.
3. 라인업·선수·성장·영입·시설·재정·소식·기록·설정으로 이동합니다.

## 적용 규칙

- 선수 수, 승패무, 자금과 실제 다음 경기의 홈·원정을 봅니다. 운영비 카드에는 예상 수입·지출과 패배·승리 때의 손익을 표시합니다.
- 운영비 카드의 "수입·지출 상세 보기"를 펼치면 입장료·시설 수입·리그 배당금·MLB 정기 후원, 급여·유지비·이전 미지급금·대출 상환·예상 잔액을 확인합니다. 3득점 및 현재 선수단·시설·입장료 기준입니다.
- 홈에 치어리더·선수 장식·능력치 기대주를 표시하지 않습니다.
- 왼쪽 아래에 “야구는 언제 끝날지 몰라도 오늘은 한다.” 표지판을 둡니다.

## 막히는 조건과 예외

- 첫 준비 전에는 일반 경기 시작 대신 준비 단계로 안내합니다.
- 경기 수입을 받아도 지급할 비용이 부족하면 미지급될 금액을 별도로 알립니다. 경기 진행 중이나 시즌 결과가 미확정일 때는 다음 경기 예상의 대기 이유를 표시합니다.

## 직접 확인할 항목

- [ ] 홈에서 필요한 기능으로 이동할 수 있는지 봅니다.
- [ ] 기대주와 하단 검사 버튼이 없고 구단 정보는 보이는지 봅니다.

## 현재 확인된 범위

현재 홈 화면 확인. 기대주 제거·선수 장식 제거 자동검사 통과. A6 관련 자동 검사 95개 통과. 임시 브라우저 화면에서 280px 홈 카드와 넓은 상세 표시를 확인했고, 실제 경기는 진행하지 않았습니다. 홈·원정은 실제 다음 경기 기준, 득점은 3점 가정의 참고값입니다.

자동검사 통과와 사용자 확인은 구별합니다. 위 체크박스는 직접 플레이하며 확인할 때 표시합니다.
