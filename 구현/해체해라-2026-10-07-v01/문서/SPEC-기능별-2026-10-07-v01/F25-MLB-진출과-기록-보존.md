# F25 MLB 진출과 기록 보존

잘 키운 선수를 더 큰 무대로 보내고 다음 육성을 위한 구단 자금을 받습니다.

**분야:** 구단 운영  
**상태:** 현재 구현 · 시험값 포함  
**기준:** 2026-10-07 로컬 구현본

[전체 기능 목차](README.md)

## 찾는 곳

선수 관리 → MLB 진출 제안 보기/조건 보기 · 기록실 → MLB 진출 명단

## 화면에서 할 일

1. 선수를 고르고 타격·투구 평가와 출전 조건을 확인합니다.
2. 제안에서 성공 확률·이적료·실패 시 애정도·남는 선수 수를 읽습니다.
3. MLB 진출 도전을 누르면 성공 또는 실패를 한 번 결정합니다. 취소하면 아무 변화가 없습니다.
4. 결과를 확인하고 진출 명단에서 당시 모습·능력·개인 누적 기록을 다시 봅니다.

## 적용 규칙

- 게임용 가상 진출 규칙이며 현실 MLB 계약 규정을 재현하지 않습니다. 자동 매각 없이 이용자가 선수별로 직접 도전합니다.
- 기본 조건은 출전 5경기 이상, 타격(컨택·파워·선구안) 또는 투구(구속·제구·스태미나) 3능력 평균 75 이상입니다. 더 높은 평균으로 타자/투수 평가를 정하며 같으면 타자로 표시합니다.
- 경기 종료·첫 선수 준비 완료·유효 계약·애정도 1 이상·보유 10명 이상이어야 합니다. 성공 후 최소 9명을 유지합니다. 후임 선수 무료 지급은 없습니다.
- 성공률 기본 35% + 기준 평균을 넘는 1점마다 2%p, 최대 85%입니다. 실제 판정에 사용하는 확률을 정수 퍼센트로 표시합니다.
- 성공 이적료는 기본 5,000만원 + 기준 평균을 넘는 1점마다 400만원입니다. 기본 설정에서 평균 75는 5,000만원, 90은 1억 1,000만원, 100은 1억 5,000만원입니다. 1만 원 단위로 반올림합니다.
- 성공하면 구단 자금과 수입 내역에 이적료를 한 번만 더하고 현재 선수단에서 제외합니다. 빈 선발 자리는 후보 선수로 보충합니다. 승리 수·트로피·기존 득실점·다른 선수 능력은 바꾸지 않습니다.
- 실패하면 수입 없이 애정도 −20이며 0 미만으로 내려가지 않습니다. 애정도가 0이면 기존 규칙대로 팀을 떠납니다. 실패 뒤에도 남아 있다면 구단이 3경기를 더 마친 후 재도전할 수 있습니다.
- 조건·금액·확률·불이익·재도전 경기 수는 설정 → 시험 수치 조정에서 변경할 수 있는 시험값입니다. 조건과 재도전 경기 수는 최소 1, 확률은 0~1, 애정도 감소는 0~100입니다. 이미 지급한 이적료·과거 결과·대기 종료 시점은 다시 계산하지 않습니다.
- 제안을 읽거나 취소할 때는 추첨하지 않습니다. 확인 사이에 능력·계약·선수단·설정이 바뀌면 다시 제안을 열어야 합니다. 같은 버튼을 반복 눌러 이적료나 실패 감소를 중복 반영하지 않습니다.
- 진출 당시 선수 모습·등번호·유니폼·능력·개인 기록·이적료를 저장합니다. 지난 경기 선수 목록을 보존해 결과 화면과 경기 기록이 깨지지 않게 합니다.
- 기록실에는 전체 성공 명단과 누적 이적료, 최근 20회 도전 기록을 표시합니다. 미확인 결과는 불러오기 후 다시 알리고, 확인한 결과는 자동으로 반복하지 않습니다.
- 기존 저장에 MLB 자료가 없어도 불러올 수 있습니다. 백업·불러오기·두 저장칸 분리 및 손상 자료 보호를 유지합니다.

## 막히는 조건과 예외

- 진행 중이거나 일시정지한 경기에서는 도전할 수 없습니다. 계약 만료 선수는 먼저 재계약해야 합니다.
- 9명 이하일 때는 제안 조건만 확인할 수 있습니다. 먼저 선수를 영입해야 합니다.
- 실패로 이적할 가능성은 도전 전에 표시합니다. MLB 진출 이후 실제 미국 리그 경기·귀국은 이번 기능에 포함하지 않습니다. 진출 성공 인원에 따른 업적 배지는 F26에서 확인합니다.

## 직접 확인할 항목

- [ ] 도전 전 확률·이적료·실패 애정도·선수단 잔여 인원 안내를 읽고 취소해 봅니다.
- [ ] 성공하면 자금이 한 번만 늘고 9명 편성이 유지되며 진출 선수 기록을 볼 수 있는지 확인합니다.
- [ ] 실패 후 애정도 감소와 3경기 재도전 대기, 새로고침 뒤 결과·기록 보존을 확인합니다.

## 현재 확인된 범위

MLB 14개 단위 검사에서 조건 경계·성공/실패·금액·중복 방지·9명 보호·애정도 0 이적·옛 저장·잘못된 저장·재도전 대기·기록 보존을 확인했습니다. 브라우저에서 실제 제안·취소·성공/실패·명단·저장 검증·미확인 결과 복원·계약/인원/경기 조건 등 19개 검사와 기존 경기52·계약15 검사를 통과했습니다. 그림과 결과 화면은 별도 확인 자료로 보관합니다.

자동검사 통과와 사용자 확인은 구별합니다. 위 체크박스는 직접 플레이하며 확인할 때 표시합니다.
