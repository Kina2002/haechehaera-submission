# 구단 사건 애니메이션 콘셉트

2026-10-07 사용자 피드백에 따라 장소와 행동을 구체화한 이벤트 5종입니다. 이벤트마다 문서와 애니메이션 코드를 따로 관리합니다.

| 이벤트 | 장면 흐름 | 문서 |
| --- | --- | --- |
| 후보 선수에게도 응원가가 | 경기 후 퇴장 → 갑작스러운 응원가 → 멈춰 돌아봄 → 눈물과 감사 인사 | [후보 선수 응원가](후보-선수-응원가.md) |

컵 쌓기 대결·응원 박자 엇갈림·기념사진 늦게 합류는 사용자 요청으로 후보에서 제외했습니다. 게임의 사건 목록과 미리보기에도 포함하지 않습니다.

## 게임에서 보기

1. 새로고침 후 구단을 불러옵니다.
2. 설정 → 구단 사건 연출 미리보기를 누릅니다.
3. 사건을 선택해 처음부터 재생하거나 1~4 장면 버튼으로 멈춰 봅니다.
4. 다시 재생은 처음으로 돌아갑니다. 미리보기와 재생은 선수 수치를 바꾸지 않습니다.

새 5종은 10초, 기존 사인회·기부 등 5종은 6.6초입니다. 등장 선수와 구단 유니폼은 실제 구단 자료를 사용합니다. 경기 후 발생 확률은 기존 32%이며 조건에 맞는 종류 중 하나만 발생합니다.

효과와 저장 규칙은 [F21 팬 애정도와 구단 소식](../SPEC-기능별-2026-10-07-v01/F21-팬-애정도와-구단-소식.md)에서 확인할 수 있습니다. 신규 레슨(+18팬)·새치기(−15팬)의 수치는 시험값입니다.
